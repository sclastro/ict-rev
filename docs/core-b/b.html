系統軟件System Software

System Software系統軟件
建議課時 6 小時Suggested time: 6 hours課本第 4 章Textbook Ch. 4

2.1課程要求

了解系統軟件和應用軟件的功能，以及硬件、系統軟件、應用軟件和用戶之間的關係；簡述操作系統的基本功能，描述常用的操作系統，並說明它們的差異和應用；陳述實用程式及驅動程式的功能和用途（實用程式包括數據壓縮、病毒偵測、檔案管理、磁碟重組及系統監察軟件，毋須了解技術細節）；區分各類電腦系統的特性及應用，包括成批工件處理系統、網上互動系統、實時系統、並行式處理系統、分布式處理系統和虛擬化。

2.2系統軟件與應用軟件

比較 系統軟件（system software） 應用軟件（application software）
作用 管理和控制硬件資源，為應用軟件提供運作平台 在系統軟件提供的平台上，替用戶完成特定工作
組成或類別 操作系統、實用程式、驅動程式 生產力軟件（文書處理、試算表、簡報、數據庫）、通訊軟件（瀏覽器、電郵）、多媒體軟件、娛樂軟件、教育軟件
安裝 通常預先安裝，電腦必須有操作系統才能運作 用戶按需要選擇安裝

硬件、軟件與用戶的關係：

用戶 ↔ 用戶界面 ↔ 應用軟件 ↔ 系統軟件（操作系統）↔ 硬件

系統軟件是應用軟件與硬件之間的中介。沒有操作系統，應用軟件不能運行。

✔ 〔樣本試卷卷一乙 1(b)〕我們不會用系統軟件播放影片。為甚麼？

系統軟件負責管理硬件資源，包括操作系統、實用程式和驅動程式，在硬件和用戶之間提供界面。播放影片是應用軟件（例如媒體播放程式）的工作。

✔ 〔2024 卷一乙 4(c)〕某點陣顯示板運作時，應用軟件和系統軟件各有甚麼功能？

應用軟件：讓用戶管理、編輯或選擇要顯示的圖案。

系統軟件：驅動程式讓系統與顯示板溝通、控制顯示板。

2.3用戶界面

圖形用戶界面（GUI） 命令行界面（CLI）
操作方式 以指標器點選圖示、選單 以鍵盤輸入文字指令
優點 容易學習，毋須記憶指令；外觀吸引 消耗的電腦資源較少；熟練用戶可快速執行複雜工作；適合成批處理重複的工作
缺點 消耗較多記憶體及處理能力 要記憶指令，學習時間長
主要用戶 一般用戶 系統管理員、程式員

例：要按一個文字檔的資料在伺服器上一次建立數百個用戶帳戶，用 CLI 執行指令比用 GUI 逐一建立有效率。

2.4操作系統的功能

操作系統（operating system，OS）是系統軟件中必不可少的部分，主要功能如下：

功能 說明
管理輸入及輸出設備 控制周邊設備，經驅動程式與設備溝通
管理記憶體 把 RAM 分配給不同程式
管理檔案 組織資料夾、在主記憶體和輔助儲存設備之間傳送檔案、分配儲存空間、保護及還原檔案
管理處理器及工作 分配硬件資源，安排工作的執行次序
管理網絡通訊 設定及協調網絡活動
管理系統保安 用戶帳戶、密碼、存取權限
提供用戶界面 讓用戶操作電腦、執行應用軟件

⚠ 〔2025 卷一甲第 12 題〕下列哪些是操作系統的功能？(1) 管理輸入及輸出設備 (2) 管理系統保安 (3) 管理電腦記憶體

✔ 三項都是。只有 45% 考生答對，36% 考生漏選「管理系統保安」。

⚠ 下列不是操作系統的功能：永久儲存用戶程式〔2023 卷一甲第 16 題〕；播放影片檔案〔2024 卷一甲第 21 題〕；編輯文字檔案。

經常更新操作系統，可修補保安漏洞，減少病毒入侵的機會〔2023 卷一甲第 40 題〕。

2.5常見的操作系統

類別 例子 特點
網絡操作系統 Windows Server、Linux 用於伺服器；多用戶；提供集中儲存、共享周邊設備及進階保安
桌上操作系統 Microsoft Windows、macOS 用於桌上電腦及筆記型電腦；硬件擴充性及軟件相容性高
流動操作系統 Android、iOS、iPadOS 用於智能電話、平板電腦、穿戴式設備及物聯網設備；以觸控 GUI 為主

其他比較：

  • 開放源碼與專有：Linux 和 Android 屬開放源碼；Windows、macOS 和 iOS 屬專有軟件。
  • 硬件：Windows 可在不同品牌的硬件上運行；macOS 只在 Apple 的電腦上運行。
  • 多工處理：現今的操作系統都可以同時執行多個程式。早期的磁碟操作系統（DOS）屬單工處理，只有命令行界面。

2.6相容性與跨平台

為某操作系統編寫的程式，一般不能直接在另一操作系統上安裝或執行。

⚠ 〔2025 卷一乙 7(b)(ii)〕在平板電腦上運行的程式，不能安裝在筆記型電腦上。為甚麼？

✔ 兩部電腦的操作系統不同；或該程式不是跨平台的。

✘ 較弱考生寫「系統不同」，術語不準確。必須寫「操作系統」。

⚠ 〔2023 卷一乙 1(c)〕在瀏覽器上使用文書處理軟件，或在筆記型電腦上安裝文書處理軟件，各有甚麼好處？安裝失敗可能是甚麼原因？

✔ 瀏覽器版本：功能自動更新；毋須安裝；可在其他電腦使用。安裝版本：毋須連接互聯網；功能較多。

✔ 安裝失敗：與操作系統不相容；儲存空間不足。

✘ 「電腦系統不相容」不給分，「操作系統」不可以寫成「電腦系統」，但可寫「系統軟件」。只寫「節省儲存空間」亦不給分，要說明是因為毋須下載及安裝。

跨平台指軟件可在多種操作系統上運行。例如 Java 程式先編譯成字節碼，任何裝有 Java 虛擬機器（JVM）的操作系統都可以執行。網頁版的應用程式只需瀏覽器，亦可在不同操作系統上使用。

✔ JVM 只能執行 Java 程式。一個不是用 Java 編寫的舊遊戲，不會因為安裝了 JVM 便能在新操作系統上運行。

2.7實用程式

實用程式（utility program）協助操作系統保護數據、優化系統和管理資源。

實用程式 功能
檔案管理程式 複製、刪除、重新命名及以目錄結構組織檔案
檔案壓縮程式 把一個或多個檔案壓縮成較小的檔案，方便傳送及備份
防毒軟件 以病毒定義檔找出已知病毒，清除、刪除或隔離受感染的檔案；須定期更新病毒定義檔
軟件防火牆 監察及控制電腦傳入和傳出的網絡流量，阻止未經授權的存取
備份程式 為選定檔案或整個磁碟製作副本，可按排程自動執行
數據還原程式 還原損壞或意外刪除的檔案
程式卸除程式 完全移除應用程式及其相關檔案
磁碟掃描程式 檢測及修正儲存設備上的邏輯錯誤
磁碟重組程式 把傳統硬碟上分散的檔案碎片重新排列到連續的位置，加快存取速度
磁碟清理程式 刪除暫存檔案及不需要的檔案，騰出儲存空間
系統監察程式 顯示正在執行的程序、CPU 及記憶體使用情況、網絡流量

✔ 磁碟重組只適用於傳統硬碟。SSD 隨機存取，碎片不影響速度，而且重組會增加不必要的寫入；SSD 改用 TRIM 功能管理未使用的區塊。

系統監察程式可顯示正在執行的程序、記憶體使用情況和網絡流量〔樣本試卷卷一甲第 16 題〕。伺服器在繁忙時段反應變慢，可用系統監察程式找出原因〔改編自 2026 模擬試卷卷一乙 5(c)〕。

⚠ 電腦感染勒索軟件後，應立即中斷網絡連接並關機。只執行防毒程式並不足夠〔2024 卷一甲第 18 題；詳見單元 C〕。

2.8驅動程式

驅動程式（driver program）讓操作系統與特定的周邊設備溝通。考評局把驅動程式視為操作系統的重要組成部分。

  • 操作系統已內置常用設備（例如鍵盤、滑鼠、部分打印機）的驅動程式，因此這些設備接上後可立即使用〔2023 卷一甲第 19 題〕。
  • 其他設備的驅動程式由製造商提供。不同操作系統要用不同的驅動程式。
  • 新打印機無法使用的軟件原因：沒有安裝驅動程式，或驅動程式已損壞〔2012 練習卷卷一乙 3(d)(iii)〕。

⚠ 〔2024 卷一甲第 17 題〕驅動程式 P 和 Q 分別用於視像會議和打印。下列哪項描述合理？

✔ P 讓操作系統與網絡攝影機互相溝通。

✘ 22% 考生選「Q 可在不同操作系統上執行」。驅動程式依賴操作系統，不能跨操作系統使用。驅動程式也不控制同時使用的用戶數目或打印權限。

⚠ 〔2025 卷一乙 5(b)〕打印機的驅動程式有甚麼主要功能？使用最新版本有甚麼好處？

✔ 功能：讓打印機與操作系統溝通；把打印工作轉換為打印機可執行的指令；處理打印機的錯誤訊息。

✔ 最新版本：確保與操作系統相容；提供最新功能；修正舊版本的錯誤。

只有少數考生答出驅動程式的核心功能。

2.9電腦系統的運作模式

模式 特點 例子
成批工件處理 把工作累積成一批，按排程一次處理，毋須用戶參與 薪金計算、列印銀行月結單、學校成績表、排程備份、排程病毒掃描
網上互動 經網絡接收請求，在數秒至數分鐘內回應 網上購物、網上查詢、搜尋器、網上電郵
實時 輸入數據後立即處理並回應 自動櫃員機、訂票系統、自動駕駛、保安警報、飛行模擬
並行式處理 一部電腦內多個處理器或核心同時處理工作 大數據分析、訓練人工智能模型、科學運算
分布式處理 經網絡連接的多部電腦分擔同一工作 電腦動畫渲染、大型網上服務

1. 成批工件處理

成批處理可善用電腦資源，把費時的工作安排在非繁忙時段，操作成本較低；缺點是結果不是最新的。

⚠ 〔2023 卷一乙 5(b)(i)〕健身中心的裝置持續記錄會員心跳率，每 5 分鐘把數據檔上載到伺服器。這是成批處理還是實時處理？

✔ 成批處理，因為數據在一段時間內累積，然後一次上載；系統不會立即處理最新的數據。

✘ 只寫「每 5 分鐘按排程上載」不給分，必須說明數據是累積後才處理。

✔ 〔2024 卷一乙 2(b)(ii)〕防毒軟件在兩個場合顯示警告：A「檔案含有病毒，不能執行」；B「排程掃描時發現病毒」。各屬哪種模式？

A 屬實時處理：開啟檔案時立即掃描。B 屬成批處理：按排程在特定時間一次掃描多個檔案。

2. 實時處理

實時系統必須有足夠的記憶體和處理能力，在最短時間內回應；為減少停機，通常設有後備硬件和軟件，因此建立及運作成本較高。

✔ 在不同地點設有多個櫃位的劇院訂票系統，最能形容為實時系統，因為每次購票都要立即更新座位，避免重複出售。櫃位分散在不同地方，不等於分布式處理〔樣本試卷卷一甲第 15 題〕。

3. 並行式處理與分布式處理

比較 並行式處理 分布式處理
硬件 一部電腦內有多個處理器 多部電腦經網絡連接
是否需要網絡 不需要 必須
協調 處理器共用記憶體 各電腦有自己的記憶體，經網絡交換資料；由負載管理器分配工作及整合結果

分布式處理的優點：初期成本較低；容易擴充；一部電腦故障不會令整個系統停頓，容錯能力較高；可更有效地管理資源。缺點：網絡流量過大或頻寬不足時，整體表現會變慢。

⚠ 〔2023 卷一甲第 3 題〕瑪莉只有一部沒有網絡連接的電腦。她可以使用哪些系統？

✔ 實時系統和成批處理系統。只有 37% 考生答對。分布式處理必須有網絡。

✔ 〔2025 卷一甲第 14 題〕分布式處理系統的特點

處理器之間交換資料；每個處理器都有自己的記憶體。「一個處理器要等另一個處理器完成才可執行」不是它的特點。

2.10虛擬化

虛擬化（virtualisation）把一部實體電腦的硬件資源分割成多部虛擬機器（VM）。每部虛擬機器獨立運行自己的操作系統和應用程式。

應用 說明
操作系統虛擬化 在現有操作系統內運行另一個操作系統，例如在 Windows 電腦上運行 Linux，方便軟件開發及測試
伺服器虛擬化 以虛擬機器管理程式（hypervisor）把一部實體伺服器分割成多部虛擬伺服器，是雲端運算的基礎

⚠ 〔2025 卷一甲第 13 題〕下列哪些是虛擬化的應用？

✔ 在現有操作系統內，以另一操作系統建立虛擬環境；把一部實體伺服器分割成多部虛擬伺服器。

✘ 「把多個實體硬碟合併成一個虛擬儲存設備」不算。考評局指出這屬儲存聚合，與 RAID 一類系統相似，不是虛擬機器。只有 52% 考生答對。

優點 缺點
一部伺服器可提供不同的操作系統和軟件 虛擬機器的反應比實體電腦慢，伺服器負載過重時更慢
可運行與原有電腦不相容的軟件 網絡負荷增加
善用伺服器，減少購買硬件的成本 實施成本高
減少維修及運作成本 並非所有軟件都能在虛擬環境正常運作；保安漏洞的風險較高

2.11自我檢測

1. 學校每晚自動把當天的出席記錄更新至數據庫。這屬哪種運作模式？寫出一個好處。

成批工件處理：當天的記錄累積後，按排程在晚上一次處理。好處：把工作安排在非繁忙時段，善用電腦資源。

2. 〔改編自 2026 模擬試卷卷一乙 5(b)〕商場停車場提供網上預約車位服務。應採用哪種處理系統？簡略說明。

實時處理系統。預約須立即確認並更新車位狀況，避免重複預約同一車位。

3. 〔改編自 2025 模擬試卷卷一乙 1(b)〕志偉發現，從硬碟載入檔案的時間比半年前長。在不升級硬件的情況下，他可以怎樣改善？

使用磁碟重組程式，把分散的檔案碎片重新排列到連續的位置，減少讀寫頭移動，加快存取。若儲存設備是 SSD，則應使用 TRIM 功能，而非磁碟重組。

4. 打印機製造商推出兩款打印機，客戶使用三種不同的操作系統。製造商最少要編寫多少個驅動程式？為甚麼？

2 × 3 = 6 個。驅動程式依賴設備和操作系統，每款打印機在每種操作系統上都需要各自的驅動程式。

5. 某老師在 Windows 電腦上安裝了虛擬化軟件，想在課堂示範 Linux。他還須安裝甚麼？寫出這做法的一個優點和一個缺點。

須安裝 Linux 作為客體操作系統。優點：毋須另購一部電腦。缺點：虛擬機器的反應比實體電腦慢。

6. 與一部強大的並行式處理伺服器比較，由 50 部聯網工作站組成的分布式處理系統有甚麼優點？寫出兩個。

初期成本較低；容易擴充；一部工作站故障不會令整個系統停頓，容錯能力較高。（任何兩項）
