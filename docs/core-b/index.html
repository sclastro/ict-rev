考前一頁清單

計算類

  • 時鐘頻率、頻寬、傳輸率用 1000（1 GHz = 10⁹ Hz，1 Mbps = 10⁶ bps）；檔案大小用 1024 或 1000 均可
  • B × 8 = b；計算要列式，答案要寫單位（s、ms）
  • 每個指令所需時間 = 時鐘周期數 ÷ 時鐘頻率
  • 讀取時間 = 存取時間 + 檔案大小 ÷ 數據傳輸率
  • n 位元位址 → 2ⁿ 個位址；32 位元位址最多定址 4 GB

處理器及記憶體

  • 暫存數據或指令的寄存器：ACC、IR、MDR；MAR 存位址；PC 存下一個指令的位址
  • 數據匯流排傳送數據和指令；位址匯流排傳送位址；控制匯流排傳送控制信號
  • 16 核心不等於「最多同時處理 16 個程式」
  • 位址大小影響可定址的記憶體空間，不影響時鐘頻率或傳輸速度
  • RAM「暫時」儲存正在使用的程式和數據；快取記憶體存放「經常使用」的數據和指令
  • ROM 存放啟動程式；RAM 是易失性的，不能存放啟動程式
  • 儲存設備影響存取速度，不影響運算速度

儲存及周邊設備

  • 常見儲存設備中只有磁帶屬順序存取，其餘屬隨機存取（直接存取）
  • 數據傳輸率：RAM > SSD > 硬碟
  • 投影機規格看流明、解像度、無線連接；5400 rpm 是硬碟規格
  • 改進規格要寫比較級：「更高的解像度」，不寫「高解像度」
  • 舉兩個理由要屬不同類別

系統軟件

  • 操作系統的功能包括管理系統保安；播放影片、永久儲存程式不是操作系統的功能
  • 寫「操作系統」，不寫「系統」或「電腦系統」
  • 驅動程式讓操作系統與特定設備溝通；不同操作系統需要不同的驅動程式
  • 分布式處理必須有網絡；沒有網絡仍可使用成批處理和實時處理
  • 把多個實體硬碟合併為一個虛擬儲存設備，不屬虛擬化
  • 傳統硬碟用磁碟重組程式；SSD 不需重組
