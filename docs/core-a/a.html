資訊處理簡介Introduction to Information Processing

Introduction to Information Processing資訊處理簡介
建議課時 3 小時Suggested time: 3 hours課本第 1 章Textbook Ch. 1

1.1課程要求

識別資訊系統的組成部分；區分七個資訊處理過程；分辨數據與資訊；辨識文本、數字、圖像、音效、視像等數據類型；界定資訊時代，討論知識型社會中資訊素養的重要性。

1.2資訊系統的五個組成部分

資訊系統把輸入的數據轉換為輸出的資訊，過程可以是人手或自動。

組成部分 意思 例子：學校小食部電子點餐系統
系統功能（System function） 系統要達成的目的 讓學生預先點餐及付款
數據（Data） 系統處理的原始事實，是最不可或缺的部分 學生編號、食物編號、數量
流程（Procedure） 把輸入轉為輸出的步驟或程式 接收訂單、計算金額、通知廚房
科技（Technology） 硬件、軟件、網絡及設備 平板電腦、數據庫伺服器、Wi-Fi
從業員（Personnel） 終端用戶及資訊系統專業人員 學生、小食部職員、系統分析員

資訊系統專業人員的職責：

職位 主要職責
系統分析員 研究用戶需求，設計新系統或改良現有系統
程式員 編寫及測試程式碼
數據庫管理員 管理和整理系統內的數據
網絡管理員 監察及維護網絡的運作、保安和效能
技術員 為硬件、軟件和網絡提供技術支援及維修

✔ 輸出主要由輸入數據和處理邏輯決定。 改用另一部電腦或由另一位程式員開發，只會影響處理速度或效率，不會改變同一輸入的結果〔改編自 2025 卷一甲第 2 題〕。

1.3七個資訊處理過程（資訊生命周期）

數據收集 → 數據整理 → 數據儲存 → 數據處理 → 數據分析 → 數據傳送 → 數據演示

過程 目的 電腦方式例子 非電腦方式例子
收集 為特定目的取得數據 網上問卷、感應器 訪問、紙本問卷、觀察
整理 按特定格式排列數據，準備處理 用數據庫排序、分組 人手分類問卷
儲存 存放數據以供日後提取 雲端儲存、固態硬碟 檔案夾、紙本記錄
處理 運算或轉換數據，產生有用資訊 以 SQL 計算平均分 人手計算缺席人數
分析 從處理結果中找出趨勢或規律 統計軟件、趨勢分析 開會討論統計結果
傳送 把結果送到另一系統或使用者 電郵、內聯網 郵寄、速遞
演示 以合適形式展示資訊 圖表、網頁、簡報 紙本報告

⚠ 「處理」與「分析」容易混淆。處理是計算或轉換，例如求總分；分析是解讀，例如比較兩班表現差異的原因。

1.4數據與資訊

  • 數據（Data）：未經處理、本身不具意義的原始事實，例如 80、65、72 三個分數。
  • 資訊（Information）：經處理後具有意義、有助決策的結果，例如「平均分 72.3，全班合格」。

✔ 判斷時問自己：「它是經計算或整理得來的嗎？能否直接用來作決定？」平均分、等級、排名都是資訊；個別分數是數據。

常見數據類型：文本、數字、圖像、音效、視像。各類型的檔案格式見課題 c：數據表示。

1.5資訊時代、知識型社會與資訊素養

資訊時代：電腦成為處理及管理資訊不可或缺的工具；寬頻和流動網絡令資訊能隨時隨地以低成本取得。促成資訊時代的科技包括運算技術進步、寬頻及無線網絡普及、互聯網與雲端服務，以及人工智能、大數據和物聯網。

知識型社會：以知識為最重要的資產，重視創新和終身學習。關鍵要素是電腦、通訊網絡及具備資訊素養的人。

資訊素養：具備資訊素養的人能夠判斷所需資訊的性質和範圍，有效地取得資訊，評估資訊來源，運用資訊完成任務和創造新知識，並以合乎道德和法律的方式使用資訊。

⚠ 〔2023 卷一乙 1(d)(i)〕建議兩個方法核實網上資訊。

✔ 可接受：與不同來源互相核對；查閱權威來源；檢查資料的發佈日期。

✘ 不給分：只寫「核實來源」「檢查資料」（題目本身就是這樣問）；寫「檢查網站有沒有數碼證書或 SSL」（這屬於網絡保安，不屬於資訊可靠性）。

評卷時按類別給分，類別包括完整性、準確性、權威性、客觀性、時效性、合法性。兩個答案須屬不同類別。

1.6自我檢測

1. 某學會把會員報名表的資料輸入電腦並列印會員名單。「輸入報名資料」和「列印名單」分別屬哪個資訊處理過程？

輸入報名資料屬數據儲存；列印名單屬數據演示。若題目強調把紙本資料轉成電子形式，亦可視為數據收集的一部分，作答時須扣緊題目描述。

2. 某同學說：「我每天上網三小時，所以我具備資訊素養。」試評論。

不同意。資訊素養指能判斷所需資訊、評估來源可靠性，並以合乎道德的方式運用資訊；上網時間長短不代表具備這些能力。

3. 天氣站每小時記錄一次氣溫，氣象台根據過去一星期的記錄，預測「明日最高氣溫 33 度」。哪部分是數據？哪部分是資訊？

每小時記錄的氣溫是數據，是未經處理的原始事實；「明日最高氣溫 33 度」是經分析得出、可幫助市民決定衣着和活動的資訊。

4. 就網上購買演唱會門票的資訊系統，各舉一例說明資訊系統的五個組成部分。

系統功能：讓市民網上選座位及付款。數據：顧客姓名、座位編號、付款資料。流程：選座位 → 確認 → 付款 → 發出電子門票。科技：伺服器、數據庫、網絡、顧客的智能電話。從業員：購票市民、系統管理員、程式員。

1.1Learning outcomes

Identify and examine the components of an information system; distinguish between the seven information processes; realise the difference between data and information; identify types of data such as text, number, image, audio and video; define the Information Age and discuss the importance of information literacy in a knowledge-based society.

1.2The five components of an information system

An information system accepts data as input and transforms it into information as output. The transformation can be manual or automated.

Component Meaning Example: a school tuck-shop online ordering system
Purpose What the system is designed to achieve Let students order and pay in advance
Data The raw facts the system processes; the most essential component Student number, food item code, quantity
Process The procedures or programs that turn input into output Receive orders, calculate the amount, notify the kitchen
Technology Hardware, software, networks and equipment Tablets, database server, Wi-Fi
Personnel End users and IS professionals Students, tuck-shop staff, systems analyst

Roles of information system professionals:

Role Main duties
Systems analyst Studies user requirements; designs new systems or improves existing ones
Programmer Writes and tests program code
Database administrator Manages and organises the data in the system
Network administrator Monitors and maintains the operation, security and performance of the network
Technician Provides technical support and repairs for hardware, software and networks

✔ Output depends mainly on the input data and the processing logic. Using a different computer, or having a different programmer build the system, affects only speed or efficiency; it does not change the result for the same input [adapted from 2025 P1A Q2].

1.3The seven information processes (information life cycle)

Data collection → organisation → storage → processing → analysis → transmission → presentation

Process Purpose Computer-based example Non-computer-based example
Collection Gather data for a specific purpose Online questionnaire, sensors Interview, paper questionnaire, observation
Organisation Arrange data in a set format, ready for processing Sort and group records in a database Sort questionnaires by hand
Storage Keep data for later retrieval Cloud storage, SSD Files and folders, paper records
Processing Calculate or transform data to produce useful information Calculate average marks with SQL Count absent students by hand
Analysis Find trends or patterns in the processed results Statistical software, trend analysis A meeting to discuss the statistics
Transmission Send results to another system or user Email, intranet Post, courier
Presentation Present information in a suitable form Charts, web pages, slides Printed report

⚠ Students often confuse processing and analysis. Processing means calculating or transforming, e.g. finding total marks; analysis means interpreting, e.g. explaining why two classes performed differently.

1.4Data and information

  • Data: unprocessed raw facts with no meaning on their own, e.g. the three marks 80, 65 and 72.
  • Information: processed results that are meaningful and help decision-making, e.g. "the average mark is 72.3 and the whole class passed".

✔ To decide, ask yourself: "Was it calculated or organised from something else? Can it be used directly to make a decision?" Average marks, grades and rankings are information; individual marks are data.

Common data types: text, number, image, audio and video. File formats for each type are covered in Topic c: Data Representation.

1.5The Information Age, the knowledge-based society and information literacy

Information Age: computers have become indispensable for processing and managing information; broadband and mobile networks let people obtain information anytime, anywhere, at low cost. Technologies that led to the Information Age include advances in computing, widespread broadband and wireless networks, the Internet and cloud services, and artificial intelligence, big data and the Internet of Things.

Knowledge-based society: knowledge is the most important asset; innovation and lifelong learning are valued. Its key elements are computers, communication networks and information-literate people.

Information literacy: an information-literate person can determine the nature and extent of the information needed, access it effectively, evaluate its sources, use it to accomplish tasks and create new knowledge, and use it ethically and legally.

⚠ [2023 P1B 1(d)(i)] Suggest two ways of validating information found on the Internet.

✔ Accepted: cross-check with different sources; check authoritative sources; check the date / time of publication.

✘ No marks: simply "verify / validate / check the source" (that is what the question asks — you must say how); "check whether the source has a digital certificate / SSL / digital watermark" (that is digital security, not information reliability).

Marking is based on categories: completeness, accuracy, authority, objectivity, timeliness and legality. Your two answers must come from different categories.

1.6Self-test

1. A club types the data from members' application forms into a computer and prints a membership list. Which information processes are "typing in the application data" and "printing the list"?

Typing in the application data is data storage; printing the list is data presentation. If the question stresses converting paper records into electronic form, typing in can also be seen as part of data collection — always follow the wording of the question.

2. A student says, "I spend three hours online every day, so I am information literate." Comment on this statement.

Disagree. Information literacy means being able to identify the information needed, evaluate the reliability of sources and use information ethically; the time spent online does not show these abilities.

3. A weather station records the temperature every hour. Based on last week's records, the Observatory forecasts "a maximum temperature of 33 degrees tomorrow". Which part is data and which part is information?

The hourly temperatures are data: raw facts that have not been processed. "A maximum temperature of 33 degrees tomorrow" is information: it is the result of analysis and helps people decide what to wear and what to do.

4. For an information system that sells concert tickets online, give an example of each of the five components of an information system.

System function: lets the public choose seats and pay online. Data: customer names, seat numbers, payment details. Procedure: choose seats → confirm → pay → issue e-tickets. Technology: servers, database, network, customers' smartphones. Personnel: ticket buyers, system administrator, programmers.
