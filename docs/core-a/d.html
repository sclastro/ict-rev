數據操縱和分析

Data Manipulation and Analysis
建議課時 20 小時課本第 5、6 章

4.1 課程要求

試算表：使用儲存格參照（課程文件稱「單元格參照」）、函數和數學、邏輯及關聯運算符；以一項或多項準則篩選、搜尋、排序數據；在多個工作表之間處理數據；運用樞紐分析表、樞紐分析圖和「假設」情境分析數據，辨別趨勢，作有根據的決定。

數據庫：以數據庫管理系統建立及維護簡單的數據庫；建立表單輸入數據；以查詢在單一數據表中選擇、篩選及排序數據；追蹤及闡釋簡單的 SQL 語句；按對象製作及格式化報表。

4.2 考評局提供的函數及指令清單

樣本試卷答題簿末頁列出以下函數及指令供考生參考。考試範圍以這份清單為準。

試算表

  • 常數：TRUE、FALSE
  • 運算符：+ - * / < > = <> <= >= &
  • 函數：INT、RAND、SQRT、ROUND、AND、NOT、OR、LEFT、LEN、MID、RIGHT、AVERAGE、COUNT、COUNTIF、MAX、MIN、RANK、SUM、SUMIF、FIND、XLOOKUP、IF

SQL

  • 常數：TRUE、FALSE
  • 運算符：+ - * / > < = >= <= <> % _ '、AND、NOT、OR
  • 指令：AVG、MAX、MIN、SUM、AS、BETWEEN、BY、ASC、DESC、DISTINCT、FROM、GROUP、HAVING、LIKE、NULL、ORDER、SELECT、WHERE

（樣本試卷的 SQL 清單沒有列出 COUNT，但 2024 年試題曾使用 COUNT(*)，應一併掌握。）

4.3 試算表基本概念

  • 儲存格位址 = 欄字母 + 列數字，例如 B7、AK51。
  • 公式必須以「=」開始。
  • 儲存格格式影響顯示及儲存的內容。例如輸入 000815，數值格式會變成 815；學生編號、電話號碼等有前導零的資料應設為文字格式。
  • 自動填滿可以複製內容，或延伸數列（如日期、編號）。

運算符

類別 運算符
算術 + - * / ^ %
比較 = <> > >= < <=
文字串連 &
參照 :（範圍，例如 A1:B10）、,（聯合，例如 A1:A5, D2:D6）

⚠ 比較運算符只可以寫 <=、>=、<>，不可以寫 ≤、≥、≠、=<〔2023 卷一乙 2(a)〕。

4.4 儲存格參照

類型 寫法 複製公式時
相對參照 A1 欄和列都按移動距離改變
絕對參照 $A$1 欄和列都不變
混合參照 $A1 或 A$1 有「$」的部分不變

複製規則：先計算目標儲存格與原儲存格相差多少欄、多少列，每個沒有「$」的部分都按相同距離移動。

例子：C3 的公式是 =A$1+$B2，複製到 E5（向右 2 欄、向下 2 列）後變成 =C$1+$B4。

參照其他工作表：='工作表名稱'!B3；參照其他檔案：='[檔案名稱.xlsx]工作表名稱'!B3。

✔ 公式應參照儲存格，不要把數值直接寫進公式。 例如佣金率放在 B2，公式寫 =C6*B$2；日後佣金率改變，只須修改 B2，所有公式自動更新。

4.5 常用函數

統計函數

函數 作用 例子
SUM(範圍) 總和 =SUM(B2:B9)
AVERAGE(範圍) 平均值 =AVERAGE(C2:E2)
MAX(範圍)、MIN(範圍) 最大值、最小值 =MAX(F2:F36)
COUNT(範圍) 範圍內數值儲存格的數目 =COUNT(B2:B9)
COUNTIF(範圍, 條件) 符合條件的儲存格數目 =COUNTIF(B2:B9,"缺席")
SUMIF(範圍, 條件, 相加範圍) 符合條件的對應數值總和 =SUMIF(C2:C9,"4A",D2:D9)
RANK(數值, 範圍, [次序]) 排名；次序省略或 0 為遞減，非 0 為遞增 =RANK(B2,B$2:B$9)

條件中可以用萬用字元：* 代表任何數目的字符，? 代表一個字符，例如 "4?" 代表所有中四班別。

數學函數：ROUND(X, D) 四捨五入至 D 位小數；INT(X) 取不大於 X 的最大整數，例如 INT(−4.3) = −5；SQRT(X) 平方根；RAND() 傳回 0 至小於 1 的隨機數。

邏輯函數：IF(條件, 真值, 假值)；AND(條件 1, 條件 2, …) 全部成立才傳回 TRUE；OR(…) 任何一個成立即傳回 TRUE；NOT(條件) 取相反。

巢狀 IF 例子：=IF(B2>=80,"A",IF(B2>=50,"B","C"))

文字函數

函數 作用 例子（A1 = "Banana"）
LEN(文字) 字符數目（空格也計算） =LEN(A1) → 6
LEFT(文字, N) 最左 N 個字符 =LEFT(A1,3) → Ban
RIGHT(文字, N) 最右 N 個字符 =RIGHT(A1,4) → nana
MID(文字, S, N) 由第 S 個字符起取 N 個 =MID(A1,3,2) → na
FIND(找甚麼, 文字, [起點]) 首次出現的位置，區分大小寫 =FIND("a",A1,3) → 4

以 & 連接文字：=LEFT(B2,1)&". "&A2

XLOOKUP

=XLOOKUP(查找值, 查找範圍, 傳回範圍, [找不到時傳回], [比對模式], [搜尋模式])

比對模式 意思 典型用途
0（預設） 完全符合 按編號查名稱
−1 完全符合，否則取較小的最接近值 按分數查等級（分數下限表）
1 完全符合，否則取較大的最接近值 按人數找容量足夠的旅遊巴

例子：分數在 F2，等級表下限在 J2:J6、等級在 K2:K6，公式為 =XLOOKUP(F2,$J$2:$J$6,$K$2:$K$6,,-1)。

4.6 試算表公式：考評局常見失分

⚠ 〔2025 卷一乙 1(a)〕在 F2 輸入公式計算三次測驗的平均分，再複製到 F3:F36。

✔ =AVERAGE(C2:E2)；=SUM(C2:E2)/3 等方法亦接受。

✘ 常見錯誤是寫成 AVG（那是 SQL 的函數）。注意「=」號。

⚠ 〔2025 卷一乙 1(b)〕在 H2 輸入公式，計算平均分少於或等於 G2 的學生人數，再複製到 H3:H6。

✔ =COUNTIF($F$2:$F$36,"<="&G2)

✘ 考生表現「尚可」。不少人寫 "<=G2"，或漏了 &。一位第 5 級考生寫 '<=G2'，同樣失分。

要點：比較符號放在引號內，用 & 連接儲存格參照；引號外的 G2 才會取儲存格的值。統計範圍要用絕對參照。

⚠ 〔2024 卷一乙 1(a)(i)〕D 欄或 E 欄任何一個是 1，F 欄顯示 1，否則顯示 0。

✔ =IF(D2+E2>=1,1,0)；條件亦可寫 D2+E2>0、OR(D2=1,E2=1)；或寫 =IF(D2+E2=0,0,1)。

✘ 真假值寫成 "1","0"（加了引號就變成文字，不是數值）；OR(D2,E2)=1。

⚠ 〔2024 卷一乙 1(a)(ii)〕B85 的公式 =SUMIF(A2:A81,"S01",F2:F81) 結果正確，但複製到 B86、E85、E86 後出錯。改正 B85 的公式。

✔ =SUMIF($A$2:$A$81,A85,$F$2:$F$81)

要點：兩個範圍都要絕對參照；條件改為參照儲存格 A85，而且要用相對參照，複製到 E85 時才會變成 D85。

✘ $A85（複製到 E 欄時仍然參照 A 欄）；"S01"（寫死了條件）；範圍沒有加 $。

⚠ 〔2023 卷一乙 2(a)(b)〕

✔ =IF($C2<=$C$102,1,0)；=$D2*$E2+$E$102

✘ 大部分考生懂得用 IF，但很多人失去第二分：符號寫成 ≤、漏了「=」、把條件或數值放入引號；另有考生沒有在 E$102 加 $。

考評局 2024 年的教學建議：注意公式語法；數值不可加引號等標點；正確使用 $；函數名稱不可串錯。

4.7 排序與篩選

  • 排序（sort）：按一個或多個鍵重新排列記錄，會改變記錄的次序。多鍵排序先按主要鍵，主要鍵相同時再按次要鍵。
  • 篩選（filter）：只顯示符合條件的記錄，其餘暫時隱藏，不改變原始數據；取消篩選後全部重現。

⚠ 〔2024 卷一乙 1(a)(iv)〕記錄已排序，寫出排序方式。

✔ 首先按 DATE 遞減，再按 NAME 遞增。要從數據推斷：日期由 2024-02-28 排到 2024-02-27，同一日內姓名按字母次序。

✘ 次序顛倒（先 NAME 後 DATE），或遞增、遞減寫錯。

✔ 要找「信社學生，按分數由高至低」：先設篩選條件「學社 = 信」，再按分數遞減排序。

4.8 圖表、樞紐分析表與假設分析

圖表類型

圖表 用途
直條圖、橫條圖 比較不同類別的數值
折線圖 顯示隨時間變化的趨勢
圓形圖 顯示各部分佔整體的比例
散點圖 顯示兩組數據的相關性
雷達圖 同時比較多項指標

圖表元素：圖表標題、X 軸及 Y 軸標題、圖例、數據標籤、網格線。圓形圖沒有座標軸。2D 圖表比 3D 圖表更能準確反映數值比例。

⚠ 〔2023 卷一乙 2(e)〕以圖表展示分數最高的 5 位學生。

✔ 選擇合適的圖表類型（直條圖，1 分），並標示圖表標題、座標軸標題、數據標籤或圖例中的兩項（2 分）。

✘ 有考生畫了表格而不是圖表；有考生只為一條軸加上名稱或數據標籤。

樞紐分析表（pivot table）從大量數據建立摘要表，由四部分組成：列標籤、欄標籤、值、報表篩選。「值」可以選 SUM、COUNT、AVERAGE、MAX、MIN。樞紐分析圖以圖表形式顯示樞紐分析表。

例子：數據表有「班別、學社、分數」三欄，要製作「各學社在各班取得的總分」：列標籤 = 學社，欄標籤 = 班別，值 = 分數的總和。

⚠ 〔2023 卷一乙 2(c)〕完成樞紐分析表的設定，求每位學生的分數總和。

✔ 欄 = StudID；值 = Sum of Score（加總 Score）。

✘ 很多考生只寫 Score 而沒有指明 SUM；把欄名寫錯（如 Scores）；加入了多餘的欄位。

假設分析（What-If Analysis）：改變輸入數值，觀察對結果的影響，用於預測和規劃。工具包括分析藍本管理員（Scenario Manager）和目標搜尋（Goal Seek）。

✔ 區分：假設分析是比較不同的輸入數據組合；樞紐分析表是把同一組數據分類摘要。「改變不同參數估算每月支出」適合假設分析；「比較各分店銷售」屬樞紐分析或圖表〔樣本試卷甲部第 8 題〕。

✔ 試算表適合小型數據分析和圖表製作；DBMS 適合大量結構化數據、多人存取及存取權限控制。試算表不宜直接分析大數據，因為工作表可容納的列數有限，處理大量數據時效率低〔樣本試卷乙部 2(b)〕。

4.9 數據庫：表單、查詢、報表與數據表設計

項目 作用
數據表（table） 以列（記錄）和欄（欄位）儲存數據；是數據庫必須具備的項目
表單（form） 輸入、顯示、修改記錄的圖形介面
查詢（query） 從一個或多個數據表提取符合條件的數據，可以計算和排序；可以儲存再用
報表（report） 按預設格式在屏幕顯示或列印，常用於摘要，例如成績表

使用表單的好處：提供方便的輸入環境（簡化使用者介面）；可設定有效性檢驗，例如範圍檢查；可設定數據驗證，例如輸入兩次密碼；以下拉式選單、單選按鈕、核取方塊、日期選擇器簡化輸入；一個表單可以同時修改多個數據表的相關記錄。

⚠ 表單不能縮短 SQL 執行時間，也不會減少儲存空間〔改編自 2021 卷一甲第 11 題〕。

設計數據表的步驟：列出需要記錄的項目 → 每個項目設為一個欄位 → 起一個簡短而有意義的欄名 → 決定數據類型和欄位長度 → 設定主關鍵碼 → 視乎需要加入有效性檢驗規則。

數據類型 用途 例子
文字／字符 名稱、編號、電話號碼（不作計算） NAME、TEL_NO、HKID
整數 需要計算的整數 AGE、MARK
浮點數（實數） 有小數的數值 PRICE、AREA
日期／時間 日期 DOB
布爾 是／否 PAID

✔ 電話號碼、學生編號用文字類型：不會拿來計算，而且可能有前導零或字母。 ✔ 日期用日期類型：方便排序、篩選和計算日數。若用文字，「10/2/2025」會排在「2/2/2025」之前。 ✔ 欄位長度要足夠但不浪費，例如英文姓名 20 以上，中文姓名 4 左右。

4.10 SQL SELECT 語句

書寫次序

SELECT   欄位或運算式
FROM     數據表
WHERE    篩選記錄的條件      -- 分組前篩選
GROUP BY 分組欄位
HAVING   篩選組別的條件      -- 分組後篩選
ORDER BY 排序欄位 [ASC | DESC]

示例數據表 LOAN（自擬）

SID CLASS BOOK DAYS
S01 4A B12 7
S02 4B B05 14
S01 4A B33 3
S03 4A B12 10
S04 4C B08 21
SQL 輸出 說明
SELECT SID, DAYS FROM LOAN WHERE CLASS = '4A' AND DAYS > 5 S01 7
S03 10		 AND：兩個條件都要成立
SELECT COUNT(*) FROM LOAN WHERE DAYS BETWEEN 7 AND 14 3 BETWEEN 包括兩端的值（7、14、10）
SELECT DISTINCT BOOK FROM LOAN WHERE BOOK LIKE 'B_2' B12 _ 代表一個字符；DISTINCT 刪除重複
SELECT SID, COUNT(*) FROM LOAN GROUP BY SID HAVING COUNT(*) > 1 S01 2 先分組，再篩選組別
SELECT CLASS, SUM(DAYS) FROM LOAN GROUP BY CLASS ORDER BY SUM(DAYS) DESC 4C 21
4A 20
4B 14		 每組一行；按總數遞減

運算符及關鍵字

項目 用法
比較 = < <= > >= <>
邏輯 AND、OR、NOT；優先次序 NOT > AND > OR，不肯定時加括號
LIKE % 代表零個或多個字符，_ 代表一個字符，例如 NAME LIKE 'J%'
BETWEEN a AND b 介乎 a 與 b，包括 a 和 b
IS NULL 欄位是空值（不可寫 = NULL）
IN (…) 等於清單中任何一個值
集合函數 SUM、AVG、MAX、MIN、COUNT(*)、COUNT(欄位)（不計空值）
AS 為輸出欄位定別名，例如 SUM(DAYS) AS TOTAL
ORDER BY 預設遞增（ASC）；DESC 遞減；可按多個欄位排序

追蹤 GROUP BY 輸出的步驟

  1. 先用 WHERE 剔除不符合條件的記錄。
  2. 把餘下記錄按 GROUP BY 欄位分組，每組只輸出一行。
  3. 對每組計算集合函數。
  4. 用 HAVING 剔除不符合條件的組別。
  5. 按 ORDER BY 排序；沒有 ORDER BY 時，考評局一般不要求特定次序。

⚠ 〔2024 卷一乙 1(b)(iii)〕根據首 8 個記錄，寫出以下 SQL 的輸出。

SELECT EID, COUNT(*) FROM ATTEND WHERE SIGNIN + SIGNOUT = 1 GROUP BY EID HAVING COUNT(*) > 1

✔ S03 2、S04 2（次序不拘）。

✘ 列出了不符合 HAVING 條件的組別（如 S01 1），或列出 COUNT 為 0 的員工；把 S03、S04 寫在同一行。

⚠ 〔2023 卷一乙 2(d)(ii)〕 SUM 配合 GROUP BY：部分考生沒有把兩個 S01 記錄合成一組，或沒有把 4 和 6 相加得 10。

✔ 〔2025 卷一乙 7(d)〕 SELECT CL, CNO FROM SS WHERE SER = '賣旗' AND CL LIKE '2_'，以及 SELECT CL, SUM(HR) FROM SS GROUP BY CL。考生表現「很好」，這類題目必須取分。

SQL 失分清單（整理自 2024、2025 年簡報，包括選修二甲的評卷原則）

  • ✘ 集合函數放在 WHERE 內，例如 WHERE DAYS > AVG(DAYS)。集合函數只可以用於 SELECT 或 HAVING。
  • ✘ 數值加上引號，例如 YEAR = '2012'（應寫 YEAR = 2012）；文字則必須加引號，例如 CLASS = '4A'。
  • ✘ 用 ≤ 代替 <=。
  • ✘ 子句次序錯誤，例如 ORDER BY 放在 WHERE 條件中間。
  • ✘ SELECT 了不在 GROUP BY 中、又不是集合函數的欄位。
  • ✘ 把 SQL 的 AVG 寫進試算表，或把試算表的 AVERAGE 寫進 SQL。

4.11 自我檢測

1. B2 的公式是 =$A2*B$1。複製到 D5 後，公式是甚麼？

向右 2 欄、向下 3 列：$A2 → $A5；B$1 → D$1。答案：=$A5*D$1。

2. A2:A100 是班別，C2:C100 是分數。寫出計算 4B 班總分的公式，以及 4B 班人數的公式。

總分：=SUMIF(A2:A100,"4B",C2:C100)；人數：=COUNTIF(A2:A100,"4B")。

3. 根據上文 LOAN 表，寫出 SQL 找出每班借書的平均日數，只列出平均日數超過 10 的班別。

SELECT CLASS, AVG(DAYS) FROM LOAN GROUP BY CLASS HAVING AVG(DAYS) > 10 輸出：4B 14、4C 21（4A 的平均是 20 ÷ 3 ≈ 6.67，不符合條件）。

4. 某同學寫 =IF(A2>=50,"1","0")，再以 =SUM(B2:B30) 計算合格人數，結果是 0。為甚麼？

"1" 和 "0" 加了引號，是文字而不是數值，SUM 不會把文字相加。應寫 =IF(A2>=50,1,0)。
