考前一頁清單

計算類

  • B × 8 = b；頻寬、位元率用 1000；檔案大小用 1024
  • 列式、寫單位；色彩深度用位元數（如 8），不用顏色數目（如 256）
  • n 位元 → 2ⁿ 個組合；位元數目 ≠ 組合數目
  • 二進制補碼範圍 −2ⁿ⁻¹ 至 2ⁿ⁻¹ − 1；同號相加變異號 → 溢出

概念類

  • 有效性檢驗 ≠ 數據驗證；有效性檢驗只保證合理，不保證正確
  • 傳輸錯誤用奇偶檢測或校驗和，不是檢查數位或長度檢查
  • 固定值檢查：只接受清單內的值
  • 檢查數位：完整算式（含 mod）；局限要舉出兩個得出相同檢查數位的例子
  • 主關鍵碼：獨一、非空、最少欄位；複合鍵用「+」
  • 衍生數據毋須儲存（冗餘；可用查詢產生）
  • 有損壓縮不可還原；長寬比改變會失真或出現黑邊；改顯示尺寸不改檔案大小

試算表

  • 公式以「=」開始；AVERAGE 不是 AVG
  • COUNTIF／SUMIF 條件與儲存格連接："<="&G2
  • 數值不加引號；符號用 <=，不用 ≤
  • 複製前想清楚哪部分要加 $
  • 樞紐分析表的值要寫明 SUM／COUNT 及正確欄名

SQL

  • 次序：SELECT → FROM → WHERE → GROUP BY → HAVING → ORDER BY
  • WHERE 在分組前，HAVING 在分組後；集合函數不入 WHERE
  • 文字加引號，數值不加；LIKE 的 % 與 _
  • GROUP BY 每組只輸出一行
