互聯網服務及應用Internet Services and Applications

Internet Services and Applications互聯網服務及應用
建議課時 5 小時Suggested time: 5 hours課本第 4 章Textbook Ch. 4

2.1課程要求

制訂有效策略，使用搜尋器在萬維網搜尋特定資料，並批判地分析資料來源；識別適用於網頁的圖形、音效及視像檔案格式，使用插件和播放器處理互聯網上的多媒體元素；應用檔案傳送、遙距登入、網上交談、討論區、電子郵件等互聯網服務；描述串流技術的概念及其在語音郵件、視像會議、網上廣播等方面的應用（毋須技術細節）；重視互聯網的發展和擴展對社會各種活動的意義，例如以物聯網和雲端服務建設智慧城市。

2.2搜尋器與搜尋策略

搜尋器是在互聯網上尋找資訊的網上服務，例如 Google、Bing。⚠ 搜尋器不是瀏覽器：Chrome、Edge 是瀏覽器，Google 是搜尋器。

類型 說明 例子
一般搜尋器 搜尋整個萬維網 Google、Bing、百度
專門搜尋器 只搜尋某類資料 Google Scholar（學術文章）、機票比較網站
元搜尋器 把查詢同時交給多個搜尋器，再整合結果 Dogpile

搜尋器以網絡爬蟲自動瀏覽網頁並收集內容，再由索引程式把內容編成索引；用戶輸入關鍵字後，搜尋器從索引中找出結果，並按相關程度、時效、網站權威性、用戶體驗等因素排列。不同的搜尋器使用不同的索引和排名方法，所以同一查詢會得出不同結果。

有效的搜尋策略

  1. 確定所需的資料。
  2. 選擇合適的搜尋器。
  3. 使用準確的關鍵字，例如以引號搜尋完整詞組 "香港 智慧城市"，以減號排除字詞 蘋果 -手機。
  4. 使用進階搜尋，限定語言、地區、更新日期、檔案類型或網域（例如只搜尋 .gov.hk）。
  5. 評估資料來源。
  6. 按結果修改關鍵字，再次搜尋。

評估資料來源的準則：作者或機構的資歷；網域類別（.gov、.edu 一般較可靠）；發布或更新日期；能否從多個獨立來源印證；是否屬贊助或廣告內容。

⚠ 改善搜尋結果的建議要具體並配合題目所示的界面，例如「點選『影片』分頁」「在關鍵字加上『影片』」「以引號搜尋完整詞組」。界面沒有提供的功能，或只寫「用進階搜尋」「輸入更多字」，都不給分〔改編自 2019 卷一乙 2(b)(i)〕。

2.3網頁上的多媒體檔案格式

類別 格式 適用情況
圖像 JPG 有損壓縮，檔案細，適合相片；不支援透明
PNG 無損壓縮，支援透明（可半透明），適合圖示及須透明背景的圖像
GIF 最多 256 色，支援簡單動畫
WebP 有損或無損，支援透明，檔案比 JPG、PNG 細
SVG 向量圖形，放大不失真，適合標誌及圖示
音效 MP3、AAC 有損壓縮，檔案細，普遍支援
WAV 未經壓縮，檔案很大，不宜用於網頁
FLAC 無損壓縮
視像 MP4 普遍支援，適合串流，HTML5 可直接播放
WebM 為網頁設計，壓縮效率高

BMP 未經壓縮，檔案太大，不宜放在網頁上。把文字做成圖像放在網頁上，用戶便無法複製或搜尋這些文字，放大後亦會變得模糊。

各種格式的壓縮方式及特點，詳見單元 A 課題 c 的 3.10 至 3.12 節。

2.4插件、媒體播放器與編碼解碼器

名稱 功能
插件（plug-in） 為瀏覽器加入額外功能的小程式，例如讓瀏覽器顯示某種格式的內容
媒體播放器 播放音效及視像；可以是瀏覽器內置的（HTML5 的 <audio>、<video>），也可以是獨立程式，例如 VLC
編碼解碼器（codec） 壓縮及解壓縮音效或視像數據；電腦沒有所需的編碼解碼器，播放器就不能播放該檔案

HTML5 原生支援多媒體，加上插件可能帶來保安漏洞，現時網頁已較少依賴插件。

判斷問題的方法：同一段網上影片在電腦 A 的瀏覽器能播放，在電腦 B 不能，較可能是電腦 B 的瀏覽器欠缺所需的插件或不支援該格式；下載後的影片檔案在電腦 B 能播放、在電腦 A 不能，則較可能是電腦 A 欠缺所需的編碼解碼器。

2.5互聯網服務

電子郵件

電郵地址的格式是 用戶名稱@網域名稱，例如 admin@hkict.com。電郵的標頭包括：

欄位 作用
收件人（To） 主要收件人
副本（Cc） 其他收件人；所有收件人都看到這些地址
密件副本（Bcc） 其他收件人看不到這些地址，適合大量發送通告或保障收件人私隱

「回覆」只回覆寄件人；「全部回覆」回覆寄件人及收件人欄和副本欄中的所有人，但不包括密件副本的收件人。「轉寄」把郵件傳給新的收件人，原寄件人不會知道。

把同一封郵件寄給 50 人而不想他們知道彼此的身份，應把所有地址放在密件副本欄。

⚠ 〔2025 卷一乙 3(b)(ii)〕以電郵附件傳送檔案，比以超連結傳送有甚麼優點？

✔ 電郵寄出後，附件內容不會再改動；毋須擔心連結外洩或分享設定不足；收件人總能下載附件，而超連結可能因擁有人更改設定而失效；下載郵件後，毋須連接互聯網也能開啟附件。

✘ 考生對兩種方式在運作上的分別認識不清，表現只屬「尚可」。

超連結的優點則包括：不受附件大小限制；寄出後仍可更改存取權限或更新檔案。

⚠ 〔2024 卷一乙 3(c)〕以 HTML 格式而非純文字格式發送電郵，有甚麼好處？寫出兩個。

✔ 文字可以設定格式（字型、表格、段落）；可以加入多媒體元素或超連結。

✘ 「可附加檔案」「互動性」「跨平台」不給分。兩個答案要屬不同類別。

其他互聯網服務

服務 說明
檔案傳送 FTP（客戶機─伺服器模式，須有 FTP 伺服器、用戶帳戶及權限；SFTP 會加密傳輸）、雲端儲存（方便分享及協作）、點對點分享（例如 BitTorrent，毋須中央伺服器）
遙距登入 從遠處登入及操作另一部電腦，例如在家工作、技術支援
網上交談 即時傳送文字、圖像及聲音，適合即時溝通
討論區 按主題分類，用戶發帖及回覆，毋須同時在線，討論記錄可供日後查閱
社交網絡 分享動態、相片和影片，建立人際網絡
視像會議 須有網絡攝影機、麥克風及揚聲器；軟件提供屏幕分享、文字交談、會議密碼等功能

〔2012 練習卷卷一乙 4(c)〕電郵存取協定：郵箱空間很小時，宜用 POP，因為郵件下載到電腦後會從伺服器刪除；要在不同電腦存取同一郵箱時，宜用 IMAP，因為郵件保留在伺服器，各電腦的狀態會同步。這兩個協定屬延伸內容。

2.6串流技術

串流（streaming）把音效或視像分成小段連續傳送，用戶一邊下載，一邊播放已下載的部分；播放器會先把部分內容存入緩衝區，令播放更暢順。

⚠ 不要寫「串流毋須下載」，串流其實一直在下載數據；正確的說法是「毋須等待整個檔案下載完畢便可開始播放」。〔2012 練習卷卷一甲第 25 題〕串流讓用戶在檔案完全下載前觀看影片，但不會提高數據傳輸率或影片質素。

應用 說明
語音郵件 收件人可即時收聽錄音訊息
視像會議 即時傳送雙方的影像和聲音
網上廣播 直播講座、比賽或活動，例如網上課堂
影片及音樂串流服務 網上影片平台、音樂串流

影響串流是否暢順的因素：頻寬、媒體格式、壓縮比率、幀大小（解像度）、幀率、同時觀看的人數。伺服器的硬碟容量不是主要因素。

⚠ 〔2023 卷一乙 5(c)〕健身中心直播健身課。(i) 有會員投訴即使寬頻頻寬足夠，影片有時仍不暢順。為甚麼？(ii) 健身中心決定把課堂錄影供會員下載，除解決 (i) 的問題外，還有甚麼好處？

✔ (i) 環境中有干擾；太多會員同時觀看，網絡流量繁重。

✔ (ii) 可在發布前剪輯內容；可加入字幕；會員可隨時或重複觀看；可離線觀看。

✘ 「會員可選擇想上的課」「可以之後與朋友一起看」不給分。

2.7互聯網的發展與影響

發展 說明
物聯網（IoT） 日常設備裝上感應器和網絡介面，經互聯網收集及交換數據，例如智能家居、穿戴式裝置、智能農業。設備須有 IP 位址
雲端服務 經互聯網提供運算資源：基礎設施即服務（IaaS）、平台即服務（PaaS）、軟件即服務（SaaS，例如網上辦公室軟件）。優點：隨時隨地存取、容易擴充、毋須自行維護硬件
智慧城市 結合物聯網、雲端服務和數據改善城市生活，例如交通感應器、智能燈柱、「智方便」、轉數快、開放數據
電子商貿 在網上買賣及付款
Web 3.0 強調語義網、去中心化及區塊鏈，屬延伸內容

⚠ 〔2025 卷一甲第 21 題〕常見電子商貿活動的正確步驟次序是甚麼？

✔ 收集顧客選購的產品 → 收集並核實信用卡資料 → 把交易及付款資料記錄在數據庫 → 向顧客提供交易編號 → 送貨（65% 答對）。

⚠ 〔2023 卷一乙 4(b)〕玩具店由實體店轉為網上商店，寫出一個好處和一個壞處，並簡略說明。

✔ 好處：可接觸全球市場，顧客可隨時購物。壞處：缺少面對面接觸；要額外承擔建立網頁伺服器的成本。

✘ 「沒有盜竊」「吸引更多顧客」（欠理由）、「要考慮保安」（實體店同樣有保安問題）不給分。考評局提醒答案要集中寫轉型帶來的後果。

2.8自我檢測

1. 志明說：「我用 Chrome 這個搜尋器找資料。」指出他的錯誤。

Chrome 是瀏覽器，不是搜尋器。Google、Bing 才是搜尋器。

2. 為尋找「2020 年後新加坡物聯網的發展」，建議兩項可用的進階搜尋功能。

限定地區為新加坡；限定發布日期為 2020 年之後；以引號搜尋完整詞組。（任何兩項）

3. 收集資料後，寫出兩個評估資料來源是否可信的準則。

作者或機構的資歷；網域類別；發布或更新日期；能否從多個來源印證。（任何兩項）

4. 網站要顯示一個透明背景的校徽，放大後亦不能模糊。應選用哪種圖像格式？為甚麼？

SVG。它屬向量圖形，放大不失真，並支援透明背景。

5. 下載的影片檔案在電腦 B 可以播放，在電腦 A 卻不能。電腦 A 最可能欠缺甚麼？

欠缺播放該影片所需的編碼解碼器（codec）。

6. 陳先生寄出一封郵件：收件人李小姐，副本張先生，密件副本林小姐。誰會知道林小姐也收到這封郵件？

只有陳先生（寄件人）和林小姐本人。李小姐和張先生看不到密件副本欄的地址。

7. 寫出用雲端儲存的分享連結代替電郵附件的兩個好處。

不受電郵附件的大小限制；寄出後仍可更改存取權限或更新檔案；收件人毋須在電郵中保存大檔案。（任何兩項）

8. 「串流技術讓用戶毋須下載便可觀看影片。」這句話有甚麼錯誤？應如何改寫？

串流其實一直在下載數據。應改為：「串流讓用戶毋須等待整個檔案下載完畢，便可一邊下載一邊播放已下載的部分。」

9. 除頻寬外，寫出兩個影響視像串流是否暢順的技術因素。

媒體格式；壓縮比率；幀大小（解像度）；幀率。（任何兩項）

10. 〔改編自 2025 卷一甲第 21 題〕把以下電子商貿步驟排序：(1) 送貨 (2) 提供交易編號 (3) 收集顧客的購物資料 (4) 收集並核實付款資料 (5) 把交易記錄存入數據庫

(3) → (4) → (5) → (2) → (1)。
