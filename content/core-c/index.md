單元 C 介紹電腦網絡和互聯網的運作、常用的互聯網服務、網頁的基本結構，以及網上的保安和私隱問題，分為四個課題：

| 課題 | 課時 | 對應課本章節 |
|---|---|---|
| a. 建網及互聯網基本知識 | 9 | 第 1 章（網絡概念及硬件）、第 2 章（無線通訊及接達互聯網）、第 3 章（通訊軟件及協定） |
| b. 互聯網服務及應用 | 5 | 第 4 章 |
| c. 初級網頁創作 | 3 | 第 5 章 |
| d. 網上威脅及保安 | **14** | 第 6 章（保安威脅及措施）、第 7 章（私隱）、第 8 章（加密、身份鑑定及電子交易） |

考評局指出，2025 年卷一甲部中考生表現最弱的範疇正是「互聯網及其應用」。單元 C 的題目多以家居或公司網絡、網上商店、電郵、網頁等情境出現。答題時要寫出技術名稱和具體作用，例如寫「路由器連接不同的網絡」，不寫「路由器用來上網」。

## 考前一頁清單

**網絡基礎**
- [ ] LAN 覆蓋範圍小，通常由單一機構管理；WAN 覆蓋範圍大，互聯網是最大的 WAN
- [ ] 交換器在同一網絡內按 MAC 位址轉發數據包；路由器連接不同的網絡，按 IP 位址選擇路徑
- [ ] 數據機在數碼信號與模擬信號之間轉換；網絡接達點讓無線設備連接網絡
- [ ] 路由器的 WAN 埠接數據機（互聯網），LAN 埠接電腦
- [ ] 有線媒介寫「雙扭線／UTP」「光纖」，不寫「網絡線」「TP」
- [ ] 有線比無線：連接較穩定、保安較高；無線比有線：設備擺放及移動較靈活。不寫「速度」「成本」
- [ ] 漫遊：各網絡接達點使用相同 SSID 和保安密碼匙

**TCP/IP、IP 位址與 URL**
- [ ] TCP 把數據分拆成數據包、加上序號、檢查錯誤、在目的地重組；IP 為數據包加上來源及目的地 IP 位址並選擇路徑
- [ ] 數據包可經不同路徑傳送，IP 不會預定固定路徑
- [ ] IPv4：32 位元，四組 0 至 255 的十進制數；IPv6：128 位元，八組十六進制數，連續的 0 可用 `::` 代替
- [ ] DNS 把網域名稱轉換為 IP 位址；HTTP 從網頁伺服器取得網頁；HTTPS 加密傳輸的數據
- [ ] 用 IP 位址代替網域名稱也能開啟同一網頁，因為兩者指向同一部網頁伺服器
- [ ] `.edu.hk` 屬教育機構；`.hk` 是頂級網域；`https` 表示數據經加密傳送

**互聯網服務與網頁**
- [ ] 串流：一邊下載一邊播放已下載的部分；不寫「不用下載」
- [ ] 密件副本（Bcc）隱藏收件人；附件可離線開啟，超連結可在寄出後更改權限
- [ ] HTML 是純文字檔、可跨平台，不是程式語言
- [ ] 在 HTML 中縮小顯示尺寸不會縮短下載時間；長寬比改變會令圖像變形
- [ ] 圖像未能顯示：路徑或資料夾錯誤、檔案遺失、檔名打錯、伺服器故障

**保安與私隱**
- [ ] 中了勒索軟件：立即中斷網絡連接並關機；預防：定期備份並離線存放
- [ ] 防火牆按規則過濾進出的網絡流量，不能清除病毒；防毒軟件要定期更新病毒定義檔
- [ ] WEP 不安全，應改用 WPA2 或 WPA3
- [ ] 私密瀏覽模式不保存瀏覽記錄和曲奇，但不能令用戶匿名
- [ ] 一次性密碼：有效時間短、只能使用一次、經另一渠道（短訊、權標、應用程式）發送
- [ ] 身份鑑定確認「你是誰」，授權決定「你可以做甚麼」

**加密與 PKI（必須寫明「誰的」「哪一把」密碼匙）**
- [ ] 保密：寄件人用**收件人的公開密碼匙**加密，收件人用**自己的私人密碼匙**解密
- [ ] 證明來源（數碼簽署）：寄件人用**自己的私人密碼匙**簽署，收件人用**寄件人的公開密碼匙**核實
- [ ] 網站使用 HTTPS 前要申請數碼證書；用戶用網站的公開密碼匙，網站用自己的私人密碼匙
- [ ] 密碼匙越長，可能組合越多，破解越費時；傳輸時間不變
- [ ] 數碼證書由核證機關簽發，載有持有人資料、持有人的公開密碼匙和核證機關的數碼簽署
