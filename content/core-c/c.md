## 3.1 課程要求

認識超文本標示語言（HTML）的基本結構，明白 HTML 是解決跨平台問題的一種方法；為目標讀者討論網頁的組織，並把網頁上載至萬維網。網頁資訊的組織包括：容易瀏覽、適當地放置連結、表格、框架及多媒體元素、顏色配搭、背景設計、字體大小及款式。學生毋須背誦 HTML 編碼，但要讀懂常見的標記，並按情境分析網頁設計。

## 3.2 HTML 的特點

**HTML（超文本標示語言）**以**標記（tag）**描述網頁的結構和內容，例如哪裏是標題、段落、圖像或超連結。「超文本」指可以連結到其他文件的文字。

| 特點 | 說明 |
|---|---|
| 標示語言 | HTML 只描述內容的結構，沒有運算、判斷或重複等邏輯，所以**不是程式語言** |
| 純文字檔 | HTML 檔案由純文字組成，可以用任何文字編輯器開啟及修改 |
| 跨平台 | 使用標準化的標記，不同操作系統和設備上的瀏覽器都能解讀及顯示 |
| 支援多媒體及格式 | 可加入圖像、音效、視像、超連結和表格，並設定文字格式 |

> ⚠ **〔2025 卷一甲第 22 題〕以下關於 HTML 的陳述，哪些正確？(1) 它是一種程式語言 (2) HTML 檔案由純文字組成 (3) 它可跨平台使用**
> ✔ **(2) 和 (3)**，只有 38% 考生答對。HTML 是標示語言，不是程式語言。

TXT 檔案同樣可跨平台，所以比較 HTML 與 TXT 時，HTML 的優點應寫「支援多媒體及超連結」「可設定文字格式」，不應寫「跨平台」。

建構網頁的三種技術：

| 技術 | 作用 |
|---|---|
| HTML | 網頁的內容和結構 |
| CSS | 網頁的外觀，例如顏色、字型、版面 |
| JavaScript | 網頁的互動功能，例如檢查表單輸入（屬選修部分 B 的範圍） |

## 3.3 HTML 文件的基本結構

```html
<!DOCTYPE html>
<html lang="zh-HK">
<head>
  <meta charset="UTF-8">
  <title>香城中學</title>
</head>
<body>
  <!-- 以下為網頁內容 -->
  <h1>歡迎蒞臨</h1>
  <p>本校創立於 <b>1975</b> 年。</p>
</body>
</html>
```

| 部分 | 作用 |
|---|---|
| `<!DOCTYPE html>` | 告訴瀏覽器這是 HTML5 文件，讓瀏覽器正確顯示網頁 |
| `<html lang="zh-HK">` | 整份文件的根元素；`lang` 屬性指明網頁的語言，有助屏幕閱讀器及搜尋器 |
| `<head>` | 存放網頁的資料，不在網頁內容中顯示，例如 `<meta>`（字元編碼等元數據）、`<title>`（瀏覽器分頁上的標題） |
| `<body>` | 網頁上顯示的內容 |
| `<!-- -->` | 註解，瀏覽器不會顯示 |

**標記與屬性的規則**

- 大部分標記成對出現，例如 `<p>` 和 `</p>`；少數標記沒有結束標記，例如 `<br>`、`<img>`、`<hr>`。
- **屬性**寫在開始標記內，提供額外資料，例如 `<img src="logo.png" width="200">`。標記可以沒有屬性；屬性的次序不影響顯示結果。
- 標記名稱不分大小寫，`<P>` 與 `<p>` 效果相同。
- 標記可以嵌套，但要按次序關閉：`<b><i>文字</i></b>` 與 `<i><b>文字</b></i>` 顯示結果相同。

## 3.4 常用標記

| 標記 | 作用 |
|---|---|
| `<h1>` 至 `<h6>` | 標題，`<h1>` 最大 |
| `<p>` | 段落 |
| `<br>` | 換行 |
| `<b>`、`<i>`、`<u>` | 粗體、斜體、底線 |
| `<strong>`、`<em>` | 強調（一般顯示為粗體、斜體） |
| `<sup>`、`<sub>`、`<small>` | 上標、下標、較小的字 |
| `<hr>` | 水平線 |
| `<div>` | 把內容分成區塊，方便編排版面 |
| `<img>` | 圖像 |
| `<a href="...">` | 超連結 |
| `<ul>`、`<ol>`、`<li>` | 無序清單、有序清單、清單項目 |
| `<table>`、`<tr>`、`<th>`、`<td>` | 表格、列、標題儲存格、儲存格 |
| `<audio>`、`<video>` | 音效、視像（HTML5），加上 `controls` 屬性會顯示播放控制 |
| `<iframe>` | 在網頁內嵌入另一個網頁或內容，例如地圖、影片 |

舊式的 `<frameset>` 框架現已不再使用，現時多以 `<div>` 配合 CSS 或 `<iframe>` 編排版面。

**讀碼練習**

```html
<table border="1">
  <tr><th>班別</th><th>人數</th></tr>
  <tr><td>5A</td><td>32</td></tr>
</table>
<a href="notice.pdf">下載通告</a>
<img src="images/hall.jpg" width="400" height="300" alt="學校禮堂">
```

這段碼顯示一個兩列兩欄、有框線的表格，第一列是標題；一個連結到 `notice.pdf` 的超連結；以及 `images` 資料夾內的 `hall.jpg`，顯示尺寸為 400 × 300 像素，未能顯示時會顯示替代文字「學校禮堂」。

## 3.5 網頁上的圖像

`<img>` 的常用屬性：

| 屬性 | 作用 |
|---|---|
| `src` | 圖像檔案的位置（必須） |
| `width`、`height` | 顯示的闊度和高度 |
| `alt` | 替代文字 |

**顯示尺寸與檔案大小**

在 HTML 改變 `width` 和 `height`，只改變圖像在瀏覽器上的**顯示尺寸**。瀏覽器下載的仍是原本的圖像檔案，所以檔案大小和下載時間都不變。要縮短下載時間，須用影像編輯軟件把圖像縮小解像度或提高壓縮比率，另存為新檔案。

> ⚠ **〔2025 卷一乙 4(a)〕Mary 公司網站上的相片原解像度為 800 × 600，她修改 HTML 碼，把顯示尺寸改為 400 × 200。(i) 相片的下載時間會縮短嗎？(ii) 顯示的相片會變形嗎？**
> ✔ (i) 不會，下載的仍是同一個相片檔案。
> ✔ (ii) 會，長寬比由 4:3 變為 2:1。
> ✘ 表現「差」。考評局指考生分不清顯示尺寸和檔案大小，只有少數考生能說明長寬比改變的影響。

要保持長寬比，只改一邊後須按比例計算另一邊。例如 1024 × 768 的圖像要顯示為 500 像素闊，高度應為 768 × 500 ÷ 1024 = **375** 像素。

**替代文字（alt）的作用**

- 圖像未能顯示時，顯示文字說明內容。
- 屏幕閱讀器把替代文字讀給視障人士，改善無障礙程度。
- 協助搜尋器理解圖像內容，有利搜尋器排名。

**圖像未能顯示的原因**

> ⚠ **〔2025 卷一甲第 23 題〕網頁在瀏覽器上未能顯示一幅圖像，可能的原因是甚麼？(1) 圖像的解像度低於屏幕 (2) 圖像檔案存放在錯誤的資料夾 (3) 網頁伺服器與瀏覽器的操作系統不同**
> ✔ **只有 (2)**（58% 答對）。解像度高低不影響能否顯示；HTML 可跨平台，操作系統不同亦不影響。

其他原因：`src` 的檔案名稱或路徑打錯；`src` 指向本機路徑（例如 `C:\photos\a.jpg`），上載後在其他電腦找不到；圖像檔案未有上載或已刪除；存放圖像的伺服器故障；檔案格式不受瀏覽器支援。

## 3.6 超連結與路徑

| 寫法 | 例子 | 說明 |
|---|---|---|
| 絕對 URL | `<a href="https://www.edb.gov.hk/">` | 連結到其他網站的資源 |
| 相對路徑 | `<a href="info/notice.html">` | 連結到同一網站內的檔案，以目前網頁所在的資料夾為起點 |
| 同頁位置 | `<a href="#contact">` | 跳到同一網頁內 `id="contact"` 的位置 |
| 電郵 | `<a href="mailto:info@abc.edu.hk">` | 開啟電郵程式並填上收件人 |

連結到同一網站內的檔案時，宜用相對路徑：網址較短；網站搬到另一個網域或伺服器時，連結毋須修改。連結到其他機構的資源時，才需要用絕對 URL。

**開啟網頁時要下載的檔案**

開啟網頁時，瀏覽器會下載 HTML 檔案，以及網頁上直接顯示的圖像、音效、視像等檔案；HTML 只是引用多媒體檔案，不會把它們存入 HTML 檔案內。超連結指向的檔案、`mailto` 連結，要待用戶點擊才會下載或開啟。同一個圖像檔案若來自兩個不同的 URL，瀏覽器會當作兩個檔案分別下載。

## 3.7 網頁的組織

設計網頁要先考慮**目標讀者**，例如長者需要較大的字體和簡單的導覽，兒童網站可多用圖像和鮮明的顏色。

| 範疇 | 設計要點 |
|---|---|
| 導覽 | 每頁位置一致的導覽選單；階層式選單；網站地圖（顯示整個網站的結構）；麵包屑導覽（顯示目前所在位置，方便返回上層）；搜尋功能 |
| 連結 | 放在顯眼及一致的位置，連結文字要清楚說明目的地 |
| 版面 | 常見的框架分為頁首（標誌、選單）、導覽區、主要內容、頁尾（版權、聯絡資料、私隱政策）；表格用來整理數據 |
| 多媒體 | 控制檔案大小以免載入太慢；不宜自動播放聲音；提供播放控制 |
| 顏色及背景 | 文字與背景要有足夠對比；背景簡潔，不要影響閱讀；全站顏色配搭一致 |
| 字體 | 大小適中、款式易讀、全站一致 |
| 無障礙 | 為圖像加上替代文字；提供調整字體大小及語言的選項 |
| 響應式設計 | 版面按屏幕尺寸自動調整，讓手機、平板電腦和電腦都容易瀏覽 |

〔2024 卷一甲第 26 題〕為朋友設計網站，要考慮多媒體元素的檔案大小和網頁是否易用；朋友電腦的儲存容量則與瀏覽網頁無關（76% 答對）。

**輸入界面**

以下拉式選單、選項按鈕或核取方塊代替文字方塊，可以減少輸入時間和輸入錯誤，並令輸入的數據格式一致。〔改編自 2025 模擬試卷卷一甲第 25 題〕用核取方塊讓用戶選擇興趣，可以減少輸入時間、減少輸入錯誤，並容許選擇多個選項。

> ⚠ **〔2024 卷一乙 3(d)(i)〕Ada 開發了讓學生觀看 PDF 試卷的網上系統，學生輸入科目和年份選擇試卷。重新設計網頁版面，改善選擇試卷、瀏覽 PDF 文件及觀看 PDF 文件三方面的易用程度，並加上註釋。**
> ✔ 選擇試卷：以下拉式選單選擇科目和年份。瀏覽文件：加入頁碼導覽、縮圖或搜尋功能。觀看文件：加入放大／縮小或全屏顯示功能。
> ✘ 沿用原本的直向導覽列不給分。考評局指部分考生混淆了「瀏覽」（在頁與頁之間移動）和「觀看」（看清楚內容）。

## 3.8 把網頁上載至萬維網

1. **製作網頁**：完成 HTML 檔案及所需的圖像、多媒體檔案，首頁通常命名為 `index.html`。
2. **選擇網頁寄存服務**：租用網頁寄存服務供應商的伺服器空間，或自設網頁伺服器。
3. **註冊網域名稱**：並建立 DNS 記錄，把網域名稱指向網頁伺服器的 IP 位址。
4. **上載檔案**：以 FTP 客戶端程式（須有伺服器位址、用戶名稱及密碼；SFTP 會加密傳輸）或寄存服務的控制台上載。
5. **測試**：檢查有沒有失效的連結，並以不同的瀏覽器和設備測試。

網站要使用 HTTPS，還須向核證機關申請數碼證書，詳見[課題 d](d.html) 的 4.12 節。

輸入 `https://www.floraworld.com.hk/` 與 `https://www.floraworld.com.hk/index.html` 都顯示同一網頁，原因是網頁伺服器把 `index.html` 設定為該資料夾的預設網頁。

超連結在本機測試時正常，上載後卻失效，可能的原因是：連結使用了本機的絕對路徑；部分檔案未有上載；伺服器上的檔案名稱大小寫與連結不同。

## 3.9 自我檢測

<details><summary>1. 有人說：「HTML 是一種程式語言，所以只能在 Windows 上使用。」指出兩個錯誤。</summary>

HTML 是標示語言，不是程式語言，它沒有運算或判斷等邏輯。HTML 檔案是純文字檔，使用標準化的標記，可以跨平台，在不同操作系統的瀏覽器上都能顯示。
</details>

<details><summary>2. 比較 HTML 與 TXT，寫出以 HTML 製作網頁的兩個原因。</summary>

HTML 支援圖像、音效等多媒體元素及超連結；HTML 可以設定文字格式和版面。不要寫「跨平台」，因為 TXT 同樣可以跨平台。
</details>

<details><summary>3. 寫出 &lt;head&gt; 部分常見的兩個標記及其作用。</summary>

`<title>`：設定在瀏覽器分頁上顯示的標題。`<meta>`：提供網頁的元數據，例如字元編碼 UTF-8。
</details>

<details><summary>4. 網頁上一幅 1200 × 900 的相片，HTML 中設定 width="300" height="225"。(a) 下載時間會縮短嗎？(b) 相片會變形嗎？</summary>

(a) 不會，瀏覽器下載的仍是原本 1200 × 900 的檔案，只是顯示得較小。(b) 不會，1200 : 900 與 300 : 225 都是 4 : 3，長寬比不變。
</details>

<details><summary>5. 寫出替代文字的兩個作用。</summary>

圖像未能顯示時，以文字說明內容；屏幕閱讀器可讀出替代文字，幫助視障人士；協助搜尋器理解圖像內容。（任何兩項）
</details>

<details><summary>6. 網頁以 &lt;img src="C:\photos\logo.png"&gt; 顯示標誌，在設計者的電腦上正常，上載後其他人卻看不到。為甚麼？應如何修改？</summary>

`src` 指向設計者電腦上的本機路徑，其他人的電腦沒有這個檔案。應把圖像一併上載到網頁伺服器，並改用相對路徑，例如 `src="images/logo.png"`。
</details>

<details><summary>7. 網頁上有兩幅來自不同 URL 的相同圖像、一個點擊時才播放 song.mp3 的連結，以及一個 mailto 連結。開啟網頁時，瀏覽器最少要下載多少個檔案？</summary>

**3 個**：HTML 檔案及兩個圖像檔案。song.mp3 要待點擊才下載；mailto 連結不涉及下載。
</details>

<details><summary>8. 為長者設計社區中心網站，寫出三項設計上的考慮。</summary>

較大的字體並提供調整字體大小的選項；文字與背景要有足夠對比；導覽簡單一致，選單位置固定；重要功能放在顯眼位置。（任何三項）
</details>
