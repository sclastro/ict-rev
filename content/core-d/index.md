## 單元 D 在新課程中的位置
| 部分 | 單元／選項 | 建議課時 |
|---|---|---|
| 必修（144 小時） | A 資訊處理 | 37 |
| | B 電腦系統基礎 | 20 |
| | C 互聯網及其應用 | 31 |
| | **D 計算思維與程式編寫** | **48** |
| | E 資訊及通訊科技對社會的影響 | 8 |
| 選修（76 小時，選兩項） | A 數據庫、B 網絡應用程式開發、C 算法與程式編寫 | 各 38 |

單元 D 是必修部分課時最多的單元。學生要學會有系統地分析問題，以偽代碼或程式流程圖表達算法，追蹤算法中變量值的轉變，並編寫、測試及改進簡單的程式。單元分為四個課題：

| 課題 | 課時 | 對應課本章節 |
|---|---|---|
| a. 問題建構和分析 | 5 | 第 1 章 |
| b. 算法設計 | 12 | 第 2 章（算法、空運行、數據類型、布爾邏輯）、第 3 章（控制結構、陣列、追蹤表、模組） |
| c. 程式開發 | **20** | 第 4 章（變量、運算符、輸入輸出）、第 5 章（序列、選擇、迭代、函數）、第 6 章（常用程式） |
| d. 程式測試及除錯 | 11 | 第 7 章（數據驗證、測試數據、錯誤類型）、第 8 章（比較算法） |

考評局指出，2025 年卷一甲部中考生在「計算思維與程式編寫」範疇表現最好，但乙部的程式題仍有不少人失分，常見原因是循環的範圍錯誤、變量未設初始值、混淆陣列的索引和內容。

**程式語言**：卷一乙部要求考生以指定程式語言編寫程式。2025 至 2027 年文憑試可用 Python、C++ 或 Pascal；2028 年起只限 Python 和 C++。本網站的程式碼一律用 Python，偽代碼則依考評局試卷的寫法（見[課題 b](b.html) 的 2.2 節）。

## 考前一頁清單

**問題建構和分析**
- [ ] 計算思維四個要素：分解、模式識別、抽象化、算法設計
- [ ] 解決問題的次序：界定問題及範圍 → 分析輸入和輸出 → 設計算法 → 編寫程式 → 測試及除錯 → 編寫文件及評估
- [ ] 界定範圍要寫清楚涉及的人物、地點、時間，令問題可以有效地分解為子問題
- [ ] 分析問題：列出輸入、處理、輸出；輸入是解決問題前必須取得的數據
- [ ] 模組化的好處：模組可重用、容易設計和測試、方便除錯、可分工同時開發；**不會**令程式執行得較快

**算法設計**
- [ ] 流程圖：橢圓形（開始／結束）、平行四邊形（輸入／輸出）、長方形（處理）、菱形（判斷）
- [ ] 前測循環（當…）可以一次也不執行；後測循環（重複…直至）最少執行一次
- [ ] 「重複…直至 條件」在條件為真時停止；「當 條件」在條件為真時繼續
- [ ] 德摩根定律：NOT (A OR B) = NOT A AND NOT B；NOT (A AND B) = NOT A OR NOT B
- [ ] 優先次序：NOT → AND → OR
- [ ] 電話號碼、學生編號用字串；平均分、金額用實數；是否會員用布爾
- [ ] 插入項目：由最後一項開始向後移；刪除項目：由刪除位置開始把後一項向前移
- [ ] 求最大值或最小值時，以第一個元素作初始值，不要以 0 作初始值

**程式開發（Python）**
- [ ] `input()` 傳回字串，計算前要用 `int()` 或 `float()` 轉換
- [ ] `/` 的結果是實數；`//` 求商；`%` 求餘數；偽代碼「(A / 2) 的餘數」即 `A % 2`
- [ ] `range(1, N + 1)` 才包括 N；`range(2, N)` 會少做一次
- [ ] 題目的陣列索引由 1 開始時，Python 程式依題目使用相同的索引，`L[0]` 不用
- [ ] 累加或計數前要設初始值；找最大值的索引時要保留陣列原有的內容

**程式測試及除錯**
- [ ] 測試數據要包括正常數據、邊界數據、不合理數據；範圍 0 至 100：試 −1、0、50、100、101
- [ ] 語法錯誤：違反語言規則，程式不能執行；邏輯錯誤：程式能執行但結果錯誤；運行時錯誤：執行期間出錯而終止，例如除以零、索引超出範圍
- [ ] 有效性檢驗確保輸入合理；數據校驗確保輸入與來源相符
- [ ] 比較算法看執行步數（比較次數）和資源運用（記憶體）；找到目標後提早停止可減少步數
- [ ] 以變量 N 代替常數 5，日後改動數據數量時只須修改一處
