## 2.1 課程要求

以一系列的步驟執行空運行，以確定其用途和輸出；界定算法的涵義，利用偽代碼及程式流程圖展示算法；簡述及討論問題的輸入及輸出要求，並設計合適的用戶界面；認識簡單數據類型（只限整數、實數、字符及布爾）及數據結構（只限字串及單陣列）的用途及性質，認識布爾邏輯（AND、OR、NOT）及真假值表；選擇適當的數據類型並討論其優點；設計及建立涉及基本控制結構（序列、選擇〔對分及多向〕及迭代）的標準算法；建立及檢視算法，例如載入及打印陣列、在陣列中加入或刪除項目；建立追蹤表；在算法中找出邏輯錯誤並更正；按要求修改算法；描述以模組設計電腦方案的好處，並養成以模組方法制定算法結構的習慣。

## 2.2 算法、偽代碼與程式流程圖

**算法**是解決問題的一系列清晰、有限、有次序的步驟。算法可以用**偽代碼**或**程式流程圖**表示。

**程式流程圖的符號**

| 符號 | 用途 | 例子 |
|---|---|---|
| 橢圓形 | 開始、結束 | 開始 |
| 平行四邊形 | 輸入、輸出 | 輸入 N；輸出 S |
| 長方形 | 處理（賦值、計算） | S ← S + N |
| 菱形 | 判斷，有「是」「否」兩個出口 | N > 4？ |
| 箭咀 | 表示執行的方向 | |
| 兩側加直線的長方形 | 預定義處理，即呼叫模組或子程式 | 計算 BMI |

**考評局試卷的偽代碼寫法**

偽代碼沒有統一的標準。下表是考評局中文試卷常見的寫法：

| 用途 | 偽代碼 |
|---|---|
| 賦值 | `X ← X + 1` |
| 輸入、輸出 | `輸入 N`、`輸出 S`、`輸出 "Not found"` |
| 對分選擇 | `如果 條件 則` … `否則` … |
| 前測循環 | `當 條件 執行` … |
| 計數循環 | `設 i 由 1 至 N` … |
| 後測循環 | `重複` … `直至 條件` |
| 求餘數、求商 | `(A / 2) 的餘數`、`(P / Q) 的商` |
| 取整數部分 | `((left + right) ÷ 2) 的整數部分` |
| 提早離開循環 | `退出循環` |
| 陣列元素 | `A[i]`，題目會註明索引範圍，例如「A[1] 至 A[N]」或「索引由 0 至 N − 1」 |

偽代碼以縮排表示哪些語句屬於選擇或循環之內。陣列的索引由 1 還是 0 開始，各題不同，必須先看清題目的說明。

| 比較 | 偽代碼 | 程式流程圖 |
|---|---|---|
| 形式 | 文字 | 圖形 |
| 優點 | 撰寫和修改較快；容易轉為程式碼 | 直觀，容易看出執行路徑 |
| 缺點 | 不及圖形直觀 | 繪畫費時；複雜算法的流程圖很大 |

**考評局的評分原則（偽代碼）**

- 評分重點是邏輯推理，輕微的語法錯誤可以接受。
- 偽代碼可以用 Python、C++ 或 Pascal 的風格：賦值寫 `←`、`=` 或 `:=` 皆可；等於寫 `=` 或 `==` 皆可；不等於寫 `<>` 或 `!=` 皆可；`≥` 與 `>=` 皆可；大小寫及單、雙引號不扣分。
- 影響邏輯或執行流程的錯誤不給分，例如欠缺括號而把 `(left + right) / 2` 寫成 `left + right / 2`。
- 題目要求以程式語言作答時，寫偽代碼不給分。

## 2.3 空運行與追蹤表

**空運行**是不用電腦，以人手逐行執行算法，記錄變量值的轉變，從而找出算法的輸出或用途，或找出錯誤。**追蹤表**把每一步（或每次迭代後）各變量的值列成表格。

空運行的方法：
1. 列出所有變量，寫下初始值；
2. 逐行執行，每次賦值都更新表中的值；
3. 遇到選擇或循環，先計算條件的真假，再決定下一步；
4. 循環結束後，按題目要求寫出輸出。

> ⚠ **〔2025 卷一甲第 38 題〕以下算法的輸出是甚麼？**
> ✔ 先設 S ← 0，A ← 3；當 A <= 9 時重複：S ← S + A；如果 (A / 2) 的餘數 = 1 則 A ← A + 1，否則 A ← 2 * A + 1；最後輸出 S。追蹤：A = 3 → S = 3，A 為單數，A = 4；A = 4 → S = 7，A 為雙數，A = 9；A = 9 → S = 16，A = 10，循環停止。輸出 **16**。
> ✘ 只有 65% 考生答對。考評局指出，失分考生追蹤單數、雙數兩個分支時出錯。

| 次數 | A（執行前） | S | A 是否單數 | A（執行後） |
|---|---|---|---|---|
| 1 | 3 | 3 | 是 | 4 |
| 2 | 4 | 7 | 否 | 9 |
| 3 | 9 | 16 | 是 | 10 |

⚠ 計數循環的控制變量會重新賦值。〔2023 卷一甲第 30 題〕A ← 5，B ← 11，C ← 7 之後執行「設 C 由 2 至 3：B ← A + B」，循環只執行兩次（C = 2、3），B 變成 16、21，輸出 A + B = **26**。只有 38% 考生答對。C 原本的值 7 不會影響循環次數。

## 2.4 數據類型與數據結構

**簡單數據類型**

| 數據類型 | 儲存的數據 | 例子 |
|---|---|---|
| 整數 | 沒有小數部分的數 | 人數、步數、頁數 |
| 實數 | 可以有小數部分的數 | 平均分、金額、體溫 |
| 字符 | 單一個字母、數字或符號 | `'A'`、`'5'`、`'#'` |
| 布爾 | 只有真（TRUE）或假（FALSE） | 是否會員、是否找到 |

**簡單數據結構**

| 數據結構 | 說明 | 例子 |
|---|---|---|
| 字串 | 一連串的字符，可逐個字符存取 | `"STEAM"`、電話號碼、學生編號 |
| 單陣列 | 一組相同數據類型的元素，以同一個名稱和索引存取 | `JS[1]` 至 `JS[5]` 儲存五名評判的分數 |

使用陣列而不用多個獨立變量的好處：可以用循環和索引處理所有元素，程式較短；數據數量改變時，只須修改陣列大小和循環範圍。

**選擇數據類型**要考慮數據的性質（是否用作計算、是否有小數、是否只有兩種狀態）、精確度和所需的記憶體：

| 數據 | 合適的類型 | 原因 |
|---|---|---|
| 電話號碼、學生編號、香港身份證號碼 | 字串 | 不用作計算；可能有前導零或英文字母 |
| 書本頁數、購買數量 | 整數 | 只有整數值 |
| 價錢、平均分、體溫 | 實數 | 可能有小數 |
| 是否有散光、是否會員 | 布爾 | 只有「是」「否」兩種狀態 |
| 班別（例如 2A） | 字串（或兩個字符） | 包含數字和字母 |

> ⚠ **〔2025 卷一乙 8(a)(ii)〕最後得分 FS 應該用甚麼數據類型？為甚麼？**
> ✔ 實數，因為 FS 是三個分數的平均值，可能有小數。
> ✘ 只寫「數值」而沒有解釋，或完全沒有寫原因。

〔樣本試卷卷一乙 9(a)〕交易金額不應用字串，因為字串內的數字不能直接用作計算；應用實數。

## 2.5 布爾邏輯與真假值表

| A | B | A AND B | A OR B | NOT A |
|---|---|---|---|---|
| 假 | 假 | 假 | 假 | 真 |
| 假 | 真 | 假 | 真 | 真 |
| 真 | 假 | 假 | 真 | 假 |
| 真 | 真 | 真 | 真 | 假 |

- AND：兩者都真才真；OR：其中一個真就真；NOT：真假互換。
- 沒有括號時，先計 NOT，再計 AND，最後計 OR。
- 判斷範圍「介乎 18 至 60（包括兩端）」要用 AND：`(A >= 18) AND (A <= 60)`；判斷「範圍以外」用 OR：`(A < 18) OR (A > 60)`。

**德摩根定律**

| 原式 | 等於 |
|---|---|
| NOT (A OR B) | (NOT A) AND (NOT B) |
| NOT (A AND B) | (NOT A) OR (NOT B) |
| NOT (X > 15) | X <= 15 |
| NOT (X = 6) | X <> 6 |

> ⚠ **〔2012 練習卷卷一甲第 29 題〕P 和 Q 分別代表 A ≥ 18 和 A ≤ 60。A 為 0、18、30、80 時，哪些值令 NOT (P AND Q) 為真？**
> ✔ NOT (P AND Q) 即 A 不在 18 至 60 之內，所以只有 **0 和 80**。
> ✘ 誤把 18 計入：A = 18 時 P 和 Q 皆真，NOT (P AND Q) 為假。

〔樣本試卷卷一甲第 27 題〕X = 1、Y = 2、Z = 3 時，`((X = 1) AND (Y > -2)) OR (Z > 3)` 為真；其餘三個選項都把 `Z > 3`（假）以 AND 連接，所以為假。

## 2.6 輸入、輸出與用戶界面

設計方案時，要先決定：用戶要輸入甚麼數據、以甚麼形式輸入、怎樣檢查輸入；程式要輸出甚麼、以甚麼形式顯示。

| 比較 | 命令行界面（CLI） | 圖形用戶界面（GUI） |
|---|---|---|
| 操作方式 | 輸入文字指令 | 點選圖示、按鈕、選單 |
| 優點 | 編寫容易；佔用資源少 | 容易使用，毋須記憶指令；可用選單限制輸入，減少輸入錯誤 |
| 缺點 | 用戶須記憶指令，容易打錯 | 編寫所需的程式碼較多 |

〔2025 卷一乙 7(a)(i)〕網上表格的「班別」欄，以下拉式選單或圓鈕代替文字框較好，因為只提供有效的班別，用戶不能輸入不存在的班別。考評局指出，下拉式選單保證的是輸入**合理**（有效），不保證輸入**正確**：學生仍可能選錯自己的班別。

## 2.7 控制結構：序列

任何算法都可以由三種基本控制結構組成：**序列**、**選擇**、**迭代**。序列即由上而下逐句執行。

**交換兩個變量的值**要用一個臨時變量：

```text
TEMP ← A
A ← B
B ← TEMP
```

⚠ 只寫 `A ← B`、`B ← A` 是錯的：第一句已把 A 原來的值覆蓋，兩個變量最後都等於 B。

〔2023 卷一乙 3(a)(i)〕交換 `A[i]` 和 `A[i-1]`：`TEMP ← A[i]`，`A[i] ← A[i-1]`，`A[i-1] ← TEMP`。

## 2.8 控制結構：選擇

**對分選擇**：條件成立做一件事，否則做另一件事。

```text
如果 MARKS >= 50 則
    輸出 "PASS"
否則
    輸出 "FAIL"
```

**多向選擇**有兩種寫法：

```text
如果 MARK >= 80 則
    GRADE ← "Distinction"
否則 如果 MARK >= 40 則
    GRADE ← "Attained"
否則
    GRADE ← "Unattained"
```

上例條件由高至低排列，一旦某條件成立，其餘條件就不再檢查。若寫成三句獨立的「如果」，每個分數都要檢查三次，而且次序錯誤時，後面的語句會覆蓋前面的結果。

> ⚠ **〔2012 練習卷卷一乙 3(c)〕阿達以三句獨立的「如果」判斷等級（MARK < 40、MARK >= 40、MARK >= 80），阿賓以嵌套的判斷寫成流程圖。哪一個算法效率較高？**
> ✔ 嵌套的算法效率較高，因為一般而言執行的比較次數較少。
> ✘ 只答「較快」而沒有說明比較次數較少。

**嵌套選擇**：選擇之內再有選擇。空運行時要先判斷外層條件，再判斷內層條件。

> ⚠ **〔2012 練習卷卷一甲第 32 題〕A ← 5，B ← 10；如果 (2 × A) > 8 則〔如果 A > (5 + B) 則 A ← B，否則 B ← A〕，否則 A ← A + 8。A 的最後值是甚麼？**
> ✔ 外層 10 > 8 成立；內層 5 > 15 不成立，執行 B ← A。A 的值不變，仍是 **5**。

〔2025 卷一甲第 32 題〕兩個算法效果相同。版本一：如果 P > 20 則 A ← P * 5，否則 A ← P * 2。版本二：先設 A ← **P * 2**，再「如果 P > 20 則 A ← A + P * 3」。P > 20 時，A = P * 2 + P * 3 = P * 5，與版本一相同。

〔2025 卷一甲第 33 題〕「如果 (K < 9) OR (K > 22) 則輸出 K」：選項 9、10、22、23 中，只有 23 會輸出。9 和 22 都不符合嚴格的「小於」「大於」。

## 2.9 控制結構：迭代

| 循環 | 偽代碼 | 檢查條件的時間 | 最少執行次數 | 適用情況 |
|---|---|---|---|---|
| 計數循環 | 設 i 由 1 至 N | 每次迭代前 | 0（N < 1 時） | 已知重複次數 |
| 前測循環 | 當 條件 執行 | 每次迭代前；條件為真才執行 | 0 | 次數未知，可能一次也不用做 |
| 後測循環 | 重複 … 直至 條件 | 每次迭代後；條件為真就停止 | 1 | 次數未知，最少要做一次 |

流程圖中，判斷框在循環體**之前**的是前測循環，在循環體**之後**的是後測循環。

> ⚠ **〔2025 卷一甲第 28、29 題〕自動售賣機每 5 個積分輸出一罐汽水。M1 先輸出汽水、N ← N − 5，再判斷 N > 4；M2 先判斷 N > 4，成立才輸出汽水、N ← N − 5。N = 10 及 N = 0 時，兩者各輸出多少罐？**
> ✔ N = 10：M1 和 M2 都輸出 **2** 罐。N = 0：**只有 M1** 輸出一罐，因為後測循環最少執行一次，未檢查積分就先輸出了汽水。
> ✘ 以為 N = 0 時兩者都不輸出，忽略了 M1 屬後測結構。

**後測循環與前測循環的轉換**：「重複…直至 條件」在條件成立時停止；改寫為「當…執行」時，要把條件取反（並注意前測循環可能一次也不執行）。

| 後測循環 | 等效的前測條件 |
|---|---|
| 直至 (A > 15) OR (B >= 12) | 當 (A <= 15) AND (B < 12) |
| 直至 X > 0 | 當 X <= 0 |

**計數循環改寫為前測循環**：要自行設定控制變量的初始值，並在循環體內遞增。

> ⚠ **〔2023 卷一甲第 29 題〕算法一以「設 i 由 1 至 5」把 N[1] 至 N[5] 相加。要以「當 (i <= 5) 執行」改寫為算法二，須加入哪兩句？**
> ✔ 循環前加 `i ← 1`，循環內加 `i ← i + 1`。
> ✘ 只有 51% 考生答對。以 `i ← 0` 作初始值的話，算法會多加一個不在 N[1] 至 N[5] 之內的 N[0]。

**無限循環**：條件永遠成立，循環永不停止。

〔2025 卷一甲第 27 題〕i ← 10；當 i > 0 時輸出 "$"。循環內必須加入 `i ← i - 1`，否則 i 永遠是 10，形成無限循環。

〔2012 練習卷卷一甲第 33 題〕S ← 1；輸入 A；當 S < 10 時 S ← S + A。只有輸入**正數**才能令 S 增加至 10 或以上；輸入零或負數會造成無限循環。

**計算循環次數**：

```text
N ← 2
當 N < 8 執行
    輸出 "*"
    N ← N + 3
```

N 依次為 2、5 時輸出，N = 8 時停止，共輸出 **2** 個「*」〔2023 卷一甲第 27 題〕。

〔2024 卷一甲第 30 題〕S ← 0，N ← 1；重複 S ← S + N、N ← N + 2，直至 N > 6；S 依次為 1、4、9，輸出 **9**。

## 2.10 陣列的標準算法

以下設陣列 A 有 N 個元素，索引由 1 至 N。若題目的索引由 0 開始，把範圍改為 0 至 N − 1。

**載入及打印陣列**

```text
設 i 由 1 至 N
    輸入 A[i]
設 i 由 1 至 N
    輸出 A[i]
```

〔樣本試卷卷一甲第 29 題〕cnt ← 1，ind ← 1；當 cnt < 100 時：cnt ← cnt + 2，AR[ind] ← cnt，ind ← ind + 1。AR[1] 至 AR[5] 依次為 3、5、7、9、11，所以 AR[5] = **11**。

**求和、計數、平均值**

```text
S ← 0
C ← 0
設 i 由 1 至 N
    S ← S + A[i]
    如果 A[i] >= 50 則
        C ← C + 1
AVG ← S / N
```

**最大值及其位置**

```text
MAX ← A[1]
P ← 1
設 i 由 2 至 N
    如果 A[i] > MAX 則
        MAX ← A[i]
        P ← i
```

- 以第一個元素作初始值，循環由第二個元素開始；求最小值把 `>` 改為 `<`。
- 不要以 0 作最大值的初始值：如果所有數都是負數，結果會錯誤地是 0。
- 只記錄位置也可以：`如果 A[i] > A[P] 則 P ← i`。

> ⚠ **〔2025 卷一乙 8(a)(i)、(b)〕五名評判的分數存於 JS[1] 至 JS[5]，JS[Smax] 為最高分，JS[Smin] 為最低分。偽代碼「Smax ← 1；設 i 由 2 至 N：如果 JS[i] > JS[Smax] 則 Smax ← i」中，判斷要執行多少次？以變量 N 代替常數 5 有甚麼好處？**
> ✔ 選手 C 的分數為 68、84、82、80、92，Smax = 5，Smin = 1，FS = (84 + 82 + 80) ÷ 3 = 82.00。判斷執行 **4 次（N − 1 次）**。以 N 代替 5，改變評判人數時只須修改一處，程式員可以一次過更新所有涉及 N 的語句。
> ✘ 混淆陣列的索引和內容，把 Smax 寫成 92、Smin 寫成 68；只答「容易修改」而沒有闡述。

**以旗標控制的搜尋**

```text
i ← 1
FOUND ← FALSE
輸入 X
當 (i <= N) AND (NOT FOUND) 執行
    如果 A[i] = X 則
        FOUND ← TRUE
    否則
        i ← i + 1
如果 FOUND 則
    輸出 i
否則
    輸出 "Not found"
```

> ⚠ **〔2024 卷一甲第 31、32 題〕上述搜尋算法中，「當 (i <= 10) ___ FLAG 執行」的空白應填甚麼？變量 FLAG 的作用是甚麼？**
> ✔ 填 **AND NOT**；FLAG 用來**控制循環**：找到後 FLAG 變成真，循環隨即停止。
> ✘ 只有 40% 考生答對第 31 題。選「OR」會令找到後仍然繼續，選「AND」則一開始條件就不成立。FLAG 不是用來儲存位置或次數。

**插入項目**：在位置 P 插入 X，要由最後一個元素開始，逐個向後移一格，否則會覆蓋未移動的數據。

```text
設 i 由 N 下至 P
    A[i + 1] ← A[i]
A[P] ← X
N ← N + 1
```

**刪除項目**：刪除位置 P 的元素，由 P 開始把後一個元素向前移。

```text
設 i 由 P 至 N - 1
    A[i] ← A[i + 1]
N ← N - 1
```

〔樣本試卷卷一甲第 33 題〕「輸入 P；K ← P；當 K <= N − 1 執行：A[K] ← A[K + 1]，K ← K + 1；N ← N − 1」的用途是**刪除陣列中第 P 個值**。

**反轉和移位**

> ⚠ **〔2025 卷一乙 6〕字符陣列 s1[0] 至 s1[4] 依次為 S、T、E、A、M。(a) 執行「設 i 由 0 至 4：s2[4 − i] ← s1[i]」；(b) 執行「ch ← s1[0]；設 i 由 0 至 3：s2[i] ← s1[i + 1]；s2[4] ← ch」。s2 的內容各是甚麼？**
> ✔ (a) M、A、E、T、S（反轉）；(b) T、E、A、M、S（向左移一格，第一個字符移到最後）。
> ✘ 把 (a) 誤當作直接複製。s2[4 − i] 表示 s1 的第一個字符放到 s2 的最後一格。

## 2.11 找出並更正邏輯錯誤、修改算法

**常見的邏輯錯誤**

| 錯誤 | 例子 | 更正 |
|---|---|---|
| 邊界錯誤 | 「介乎 18 至 30（包括兩端）」寫成 `age > 18` | 改為 `age >= 18` |
| 循環次數差一 | 要計 1 + 2 + … + 5，卻寫 `當 i < 5` | 改為 `當 i <= 5` |
| 誤用 AND／OR | 範圍檢查寫成 `(age >= 18) OR (age <= 30)`，任何年齡都成立 | 改為 AND |
| 沒有設初始值 | 累加前沒有 `S ← 0` | 循環前加上初始值 |
| 初始值放錯位置 | 把 `S ← 0` 放在循環內，每次迭代都把 S 清零 | 移到循環前 |
| 旗標遭覆蓋 | 搜尋時加了「否則 FOUND ← FALSE」，找到後又因後面的元素而重設 | 刪去「否則」部分 |

> ✔ 第 140 行 `如果 1<=F<=6 或 1<=N<=40` 應為 **AND**（兩項都要符合）；第 160 行應為 `如果 C = "A" OR C = "B"`（先確認班別有效）；第 220 行 `如果 NOT FLAG` 應為 **`如果 FLAG`**：FLAG 仍為真表示用戶名稱未通過檢查，才輸出「Invalid username」。
> ✘ 約三分之二考生不明白旗標在此的作用，只有三分之一能找出所有錯誤。

**按要求修改算法**：先找出算法中與要求有關的部分，只改那部分。

| 要求 | 修改 |
|---|---|
| 最大值 → 最小值 | 把 `A[i] > MAX` 改為 `A[i] < MIN` |

## 2.12 模組化方法

**模組**（子程式）是完成特定工作的一組語句，有自己的名稱，可以傳入**參數**，也可以傳回結果。傳回值的模組稱為**函數**，例如 `find_max(A, N)` 傳回最大值；不傳回值、只執行工作的模組稱為**程序**，例如 `print_report(A, N)`。

```text
函數 calc_bmi(W, H)
    傳回 W / (H * H)

輸入 WEIGHT, HEIGHT
BMI ← calc_bmi(WEIGHT, HEIGHT)
輸出 BMI
```

**以模組設計方案的好處**

| 好處 | 說明 |
|---|---|
| 可以重用 | 同一模組可在程式不同部分或其他項目再用，程式較短 |
| 容易設計和測試 | 每個模組較小，可以獨立測試 |
| 方便除錯和維護 | 錯誤局限在個別模組；修改一個模組不影響其他部分 |
| 分工合作 | 不同程式員可同時編寫不同模組 |
| 結構清晰 | 主程式只列出呼叫各模組的步驟，容易理解 |

> ⚠ **〔2024 卷一甲第 33 題〕以下哪些是以模組化方法編寫程式的好處？(1) 部分模組可以重用 (2) 較容易為程式除錯 (3) 可以較快地界定問題**
> ✔ 只有 (1) 和 (2)。
> ✘ 只有 42% 考生答對。模組化在**界定問題之後**才用得上，不會令界定問題較快。

〔2023 卷一甲第 33 題〕模組化的好處是模組可在其他情境重用、模組較容易設計和測試；「算法執行時間較短」不正確。模組化有時反而因呼叫模組而增加少量執行時間。
