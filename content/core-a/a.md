## 1.1 課程要求

識別資訊系統的組成部分；區分七個資訊處理過程；分辨數據與資訊；辨識文本、數字、圖像、音效、視像等數據類型；界定資訊時代，討論知識型社會中資訊素養的重要性。

## 1.2 資訊系統的五個組成部分

資訊系統把輸入的**數據**轉換為輸出的**資訊**，過程可以是人手或自動。

| 組成部分 | 意思 | 例子：學校小食部電子點餐系統 |
|---|---|---|
| 系統功能（System function） | 系統要達成的目的 | 讓學生預先點餐及付款 |
| 數據（Data） | 系統處理的原始事實，是最不可或缺的部分 | 學生編號、食物編號、數量 |
| 流程（Procedure） | 把輸入轉為輸出的步驟或程式 | 接收訂單、計算金額、通知廚房 |
| 科技（Technology） | 硬件、軟件、網絡及設備 | 平板電腦、數據庫伺服器、Wi-Fi |
| 從業員（Personnel） | 終端用戶及資訊系統專業人員 | 學生、小食部職員、系統分析員 |

資訊系統專業人員的職責：

| 職位 | 主要職責 |
|---|---|
| 系統分析員 | 研究用戶需求，設計新系統或改良現有系統 |
| 程式員 | 編寫及測試程式碼 |
| 數據庫管理員 | 管理和整理系統內的數據 |
| 網絡管理員 | 監察及維護網絡的運作、保安和效能 |
| 技術員 | 為硬件、軟件和網絡提供技術支援及維修 |

✔ **輸出主要由輸入數據和處理邏輯決定。** 改用另一部電腦或由另一位程式員開發，只會影響處理速度或效率，不會改變同一輸入的結果〔改編自 2025 卷一甲第 2 題〕。

## 1.3 七個資訊處理過程（資訊生命周期）

**數據收集 → 數據整理 → 數據儲存 → 數據處理 → 數據分析 → 數據傳送 → 數據演示**

| 過程 | 目的 | 電腦方式例子 | 非電腦方式例子 |
|---|---|---|---|
| 收集 | 為特定目的取得數據 | 網上問卷、感應器 | 訪問、紙本問卷、觀察 |
| 整理 | 按特定格式排列數據，準備處理 | 用數據庫排序、分組 | 人手分類問卷 |
| 儲存 | 存放數據以供日後提取 | 雲端儲存、固態硬碟 | 檔案夾、紙本記錄 |
| 處理 | 運算或轉換數據，產生有用資訊 | 以 SQL 計算平均分 | 人手計算缺席人數 |
| 分析 | 從處理結果中找出趨勢或規律 | 統計軟件、趨勢分析 | 開會討論統計結果 |
| 傳送 | 把結果送到另一系統或使用者 | 電郵、內聯網 | 郵寄、速遞 |
| 演示 | 以合適形式展示資訊 | 圖表、網頁、簡報 | 紙本報告 |

⚠ 「處理」與「分析」容易混淆。處理是**計算或轉換**，例如求總分；分析是**解讀**，例如比較兩班表現差異的原因。

## 1.4 數據與資訊

- **數據（Data）**：未經處理、本身不具意義的原始事實，例如 80、65、72 三個分數。
- **資訊（Information）**：經處理後具有意義、有助決策的結果，例如「平均分 72.3，全班合格」。

✔ 判斷時問自己：「它是經計算或整理得來的嗎？能否直接用來作決定？」平均分、等級、排名都是資訊；個別分數是數據。

常見數據類型：文本、數字、圖像、音效、視像。各類型的檔案格式見[課題 c：數據表示](c.html)。

## 1.5 資訊時代、知識型社會與資訊素養

**資訊時代**：電腦成為處理及管理資訊不可或缺的工具；寬頻和流動網絡令資訊能隨時隨地以低成本取得。促成資訊時代的科技包括運算技術進步、寬頻及無線網絡普及、互聯網與雲端服務，以及人工智能、大數據和物聯網。

**知識型社會**：以知識為最重要的資產，重視創新和終身學習。關鍵要素是電腦、通訊網絡及具備資訊素養的人。

**資訊素養**：具備資訊素養的人能夠判斷所需資訊的性質和範圍，有效地取得資訊，評估資訊來源，運用資訊完成任務和創造新知識，並以合乎道德和法律的方式使用資訊。

> ⚠ **〔2023 卷一乙 1(d)(i)〕建議兩個方法核實網上資訊。**
> ✔ 可接受：與不同來源互相核對；查閱權威來源；檢查資料的發佈日期。
> ✘ 不給分：只寫「核實來源」「檢查資料」（題目本身就是這樣問）；寫「檢查網站有沒有數碼證書或 SSL」（這屬於網絡保安，不屬於資訊可靠性）。
> 評卷時按類別給分，類別包括完整性、準確性、權威性、客觀性、時效性、合法性。兩個答案須屬不同類別。

## 1.6 自我檢測

<details><summary>1. 某學會把會員報名表的資料輸入電腦並列印會員名單。「輸入報名資料」和「列印名單」分別屬哪個資訊處理過程？</summary>

輸入報名資料屬**數據儲存**；列印名單屬**數據演示**。若題目強調把紙本資料轉成電子形式，亦可視為數據收集的一部分，作答時須扣緊題目描述。
</details>

<details><summary>2. 某同學說：「我每天上網三小時，所以我具備資訊素養。」試評論。</summary>

不同意。資訊素養指能判斷所需資訊、評估來源可靠性，並以合乎道德的方式運用資訊；上網時間長短不代表具備這些能力。
</details>
