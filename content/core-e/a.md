## 1.1 課程要求

了解科技創新的基本概念及其應用，例子包括通過人工智能（AI）和數據科學的圖形識別、三維打印技術、擴增實境（AR）和虛擬實境（VR）。學生應該對這些技術有實作的經驗。

## 1.2 人工智能與模式識別

**人工智能（AI）**是電腦科學的一個領域，研究怎樣令電腦和機器模擬人類的智能，例如學習、解難和決策。近年 AI 發展迅速，主要因為可以取得大量數據，加上處理器的運算能力大幅提升。

**模式識別**是 AI 最常見的用途：系統分析輸入的原始數據，找出當中的模式和規律，再把偵測到的模式分類。

| 輸入的數據 | 例子 |
|---|---|
| 圖像 | 容貌解鎖、車牌識別、識別手寫文字、從醫療影像找出病變 |
| 聲音 | 語音助理理解指令、語音轉文字 |
| 文字 | 過濾垃圾電郵、分析顧客評論的正負面意見 |

〔改編自 2025 模擬試卷卷一甲第 40 題〕客戶服務系統按顧客的訊息自動回覆、以文字描述生成新的相片背景，兩者都涉及 AI；在應用程式查看巴士的實時位置只是顯示定位數據，不涉及 AI。

AI 的分支還包括電腦視覺、自然語言處理、機械人技術和專家系統等。**自然語言處理**令電腦理解和處理人類語言，用於翻譯、聊天機器人、文字轉語音和語音轉文字；**專家系統**按某領域專家的知識推理，協助決策，例如輔助醫療診斷。這些分支屬延伸內容。

## 1.3 機器學習

**機器學習**是 AI 的一個分支：電腦從大量數據中學習，找出規律後預測或分類；數據越多，預測一般越準確。

建立機器學習模型的流程：

| 步驟 | 工作 |
|---|---|
| 1. 收集數據 | 收集大量與任務有關的數據，例如不同蔬菜的相片 |
| 2. 清理及整理數據 | 刪除重複或錯誤的數據，修正不一致之處，並按需要加上標籤 |
| 3. 訓練模型 | 讓電腦從數據中找出特徵和規律 |
| 4. 測試模型 | 以未用於訓練的數據測試準確度，不足時收集更多數據再訓練 |

**訓練模型的四種方法**

| 方法 | 訓練數據 | 例子 |
|---|---|---|
| 監督式學習 | 全部數據都有標籤（正確答案） | 以標明「蘋果」「橙」的相片訓練系統分辨水果 |
| 非監督式學習 | 數據沒有標籤，電腦按相似程度自行分組 | 按購物行為把顧客分成不同組別 |
| 半監督式學習 | 少量有標籤的數據加上大量沒有標籤的數據 | 只為部分相片加標籤，再讓系統把其餘相片分類 |
| 強化式學習 | 不用預先標記的數據；系統嘗試不同行動，按回饋（獎勵或懲罰）改進 | 下棋程式、機械人學習行走 |

> ⚠ **〔2025 卷一乙 4(b)〕瑪莉在郊野公園安裝了附有攝影機的人工智能系統偵測山火，需要挑選相片樣本訓練系統。寫出她要考慮的兩項因素。**
> ✔ 相片樣本的數量要多；樣本要包含不同情況的火（例如大小、日夜、遠近）；樣本要同時包括有火和沒有火的相片。（任何兩項）
> ✘ 考評局指出表現欠佳。不少考生只寫版權或私隱等與訓練模型無關的因素；相片的清晰度、解像度和檔案格式亦不接受。

**深度學習**是機器學習的一個分支，以多層的神經網絡（輸入層、多個隱藏層、輸出層）從大量數據中學習，用於圖像識別、語音識別等。神經網絡的細節屬延伸內容。

實作建議：使用網上的圖像分類訓練工具，以網絡攝影機拍攝兩種物件各數十張相片，訓練一個簡單的分類模型，再比較樣本數量不同時的準確度。

## 1.4 數據科學與大數據

**數據科學**結合統計學、算法和機器學習，從大量原始數據中找出隱藏的模式和有用的見解，協助決策。

一般流程：收集數碼數據 → 清除數據中的雜訊和錯誤 → 識別模式 → 把元素分類 → 分析數據並得出見解。

**大數據**是規模龐大、難以用傳統數據處理工具管理的數據集，來源包括網上購物紀錄、社交媒體、感應器和衞星影像。大數據有五個特徵（5V）：

| 特徵 | 意思 |
|---|---|
| 數量（Volume） | 數據量極大，來自海量來源 |
| 速度（Velocity） | 數據產生和需要處理的速度很快 |
| 多樣（Variety） | 數據類型多樣，包括結構化（如表格）、半結構化及非結構化（如文字、相片、影片）數據 |
| 真實性（Veracity） | 數據的可信程度和準確性參差 |
| 價值（Value） | 分析數據後可得到的商業或社會價值 |

AI 和數據科學關係密切：數據科學收集及分析大數據，AI 利用這些數據推理和預測。例如搜尋器分析大量用戶輸入的關鍵字，預測並顯示相關的結果；網上商店按顧客的瀏覽和購物紀錄推薦產品。

> ⚠ **〔樣本試卷卷一甲第 38 題〕以下哪些可以支援人工智能系統？(1) 大數據 (2) 雲端運算 (3) 機器學習**
> ✔ **(1)、(2) 和 (3)**。大數據提供訓練材料，雲端運算提供儲存空間和運算能力，機器學習令系統從數據中學習。
> ✘ 漏選雲端運算：訓練 AI 模型需要大量運算資源，常借助雲端服務。

實作建議：以試算表整理一個月的班會小食銷售紀錄，製作圖表找出最暢銷的時段，體驗由原始數據得出見解的過程。

## 1.5 物聯網

**物聯網（IoT）**是由連接網絡的實體物件組成的網絡。這些物件內置感應器，可以收集數據，與其他物件、系統和用戶交換數據，讓用戶遙距監察和控制。

| 應用 | 例子 |
|---|---|
| 智能家居 | 按光線自動調節照明；以手機遙距開關冷氣 |
| 醫療 | 穿戴式設備監測心率，把數據傳送給醫護人員 |
| 物流及零售 | 追蹤貨物位置；監察貨倉存貨 |
| 工業 | 監察機器運作，預測故障 |

物聯網也是大數據的重要來源。保安不足的物聯網設備容易被入侵，所收集的數據可能外洩，因此要更改預設密碼並定期更新韌體。

實作建議：以微型控制板連接溫度感應器，把讀數傳送到手機應用程式顯示。

## 1.6 三維打印技術

**三維（3D）打印**先以軟件設計立體模型，再由打印機逐層添加材料製成實物，所以又稱**增材製造**。材料包括塑膠、樹脂、金屬，甚至食物。

| 比較 | 熔融沉積成型（FDM） | 立體光固化成型法（SLA） | 選擇性激光燒結（SLS） |
|---|---|---|---|
| 材料 | 熱塑性線材（如 PLA、ABS） | 液態感光樹脂 | 粉末（如尼龍） |
| 原理 | 加熱熔化線材，逐層擠出 | 以紫外光逐層照射，令樹脂固化 | 以高功率激光逐層燒結粉末 |
| 優點 | 打印機和材料最便宜；容易使用；不用激光，較安全，適合家居和學校 | 表面光滑；可製作精細部分 | 成品堅固；可製作複雜形狀，毋須支撐結構 |
| 缺點 | 準確度較低；表面可見層紋，較粗糙 | 成本較高；樹脂有刺激性，須小心處理；成品要清洗和再固化 | 設備和材料昂貴，多用於工業；材料選擇較少 |

**3D 打印的好處**：可以快速、低成本地製作少量的原型，讓設計者在大量生產前測試和改良；可以按個人需要訂製產品，例如義肢、植入物、配合個人尺寸的傢俬。

實作建議：以免費的網上 3D 設計軟件設計一個印有姓名縮寫的鑰匙扣，匯出 STL 檔，再以學校的 FDM 打印機打印。

## 1.7 擴增實境、虛擬實境與混合實境

| 比較 | 擴增實境（AR） | 虛擬實境（VR） |
|---|---|---|
| 意思 | 在屏幕上把數碼資訊疊加在真實環境之上 | 以電腦模擬一個完全虛擬的世界，讓用戶沉浸其中 |
| 用戶看到的 | 真實環境加上虛擬物件 | 只有虛擬世界 |
| 互動對象 | 真實物件和虛擬物件 | 只有虛擬物件 |
| 常用設備 | 有鏡頭和屏幕的智能電話、平板電腦、AR 眼鏡 | VR 頭戴式設備，配合耳機、手部控制器 |
| 例子 | 以手機鏡頭對準文物，屏幕顯示介紹動畫；在家中預覽虛擬傢俬的擺放效果 | 虛擬參觀博物館；飛機師和外科醫生的模擬訓練；VR 遊戲 |

> ⚠ **〔樣本試卷卷一甲第 39 題〕在超級市場以智能電話鏡頭對準產品時，屏幕出現一段動畫。製作這段動畫需要以下哪些技術？(1) 數據科學 (2) 擴增實境 (3) 3D 打印**
> ✔ 只有 **(2)**。動畫疊加在鏡頭拍到的真實環境之上，屬擴增實境。
> ✘ 選 3D 打印：3D 打印製作實物，與屏幕上的動畫無關。

**混合實境（MR）**結合 AR 和 VR，讓真實物件和虛擬物件同時存在並即時互動，例如飛行模擬器以真實的操縱桿配合虛擬駕駛艙景觀。混合實境屬簡介內容。

長時間戴 VR 頭戴式設備可能引致眼睛疲勞、暈眩和頸部不適，使用時要定時休息。

實作建議：以手機的 AR 應用程式把虛擬傢俬放在課室中，比較從不同角度觀看的效果。

## 1.8 科技創新的應用

一項應用往往結合多種技術。

| 範疇 | 應用 | 涉及的技術 |
|---|---|---|
| 商業 | 網站的聊天機器人回答顧客查詢 | AI |
| | 按購物紀錄推薦產品 | AI、數據科學 |
| | 以 AR 預覽傢俬在家中的效果 | AR |
| 工業 | 以 AI 影像系統檢查產品瑕疵 | AI、數據科學 |
| | 以感應器數據預測機器故障 | AI、IoT |
| | 快速製作原型 | 3D 打印 |
| | 危險工作的安全訓練 | VR、AR |
| 醫療 | 分析醫療影像，輔助診斷 | AI、數據科學 |
| | 穿戴式設備監測健康 | IoT |
| | 打印義肢和植入物 | 3D 打印 |
| 教育 | 虛擬實地考察、模擬手術 | VR |
| | 網上學習平台按學生表現推薦內容 | AI、數據科學 |
| 家居 | 吸塵機械人自動規劃清潔路線 | AI |
| | 智能家居設備遙距控制 | IoT |

**新科技帶來的風險**：生成式 AI 可以製造以假亂真的深度偽造圖像和影片，用於散播假新聞、誤導公眾以至影響社會穩定；文物以 3D 建模和 VR 數碼化後，亦要防止數碼模型遭盜用或篡改。

〔改編自 2026 模擬試卷卷一甲第 40 題〕大衞以 AI 平台生成圖像，放進自己製作並收費的遊戲。他面對的主要風險是版權問題：生成的圖像可能含有受版權保護的內容，他卻沒有核實。

模式識別是分析輸入的原始數據，找出當中的模式和規律，再把偵測到的模式分類。例子：容貌解鎖、車牌識別、從 X 光片找出病變。
</details>

<details><summary>2. 文傑以全部標明「番茄」「青瓜」「紅蘿蔔」的相片訓練模型。他使用了哪種訓練方法？解釋原因。</summary>

監督式學習，因為所有輸入的數據都附有標籤，標明蔬菜的種類。
</details>

<details><summary>3. 某零售公司有大量沒有標籤的交易紀錄，想把購物行為相似的顧客分組。應使用哪種機器學習方法？</summary>

非監督式學習。它在沒有標籤的數據中按相似程度自動找出組別。
</details>

<details><summary>4. 文傑的模型準確度不足。在不改變訓練方法的情況下，建議一個改善方法。</summary>

收集更多、更多樣化的訓練數據（例如不同角度、光線下的相片），再重新訓練模型。
</details>

<details><summary>5. 寫出大數據 5V 中的任何兩個特徵，並解釋其意思。</summary>

數量：數據量極大；速度：數據產生和處理的速度很快；多樣：包括結構化、半結構化和非結構化數據；真實性：數據的可信程度參差；價值：分析後可得到的商業價值。（任何兩項）
</details>

<details><summary>6. 為甚麼 FDM 是家居和學校最常用的 3D 打印方法？</summary>

打印機和材料的成本最低，容易使用，而且不用激光，較安全。
</details>

<details><summary>7. 寫出 SLA 相對於 FDM 的一個優點和一個缺點。</summary>

優點：表面較光滑，可製作精細的部分。缺點：成本較高；樹脂有刺激性，要小心處理。
</details>

<details><summary>8. 寫出在製造業使用 3D 打印製作原型的一個好處。</summary>

可以快速、低成本地製作少量原型，在大量生產前測試和改良設計。
</details>

<details><summary>9. 歷史博物館推出手機應用程式：把鏡頭對準文物，屏幕即時顯示文物的資料和動畫。這應用了哪種技術？寫出一個對參觀者的好處。</summary>

擴增實境（AR）。參觀者可以一邊看真實的文物，一邊取得更多資料，內容更有趣、更容易理解。
</details>

<details><summary>10. 解釋 AR 和 VR 的一項分別。</summary>

AR 把數碼資訊疊加在真實環境上，用戶同時看到真實和虛擬物件；VR 令用戶完全沉浸在電腦模擬的虛擬世界，看不到真實環境。（或：AR 常用智能電話或平板電腦，VR 要戴頭戴式設備）
</details>

<details><summary>11. 智能家居的吸塵機械人可以怎樣應用 AI 和 IoT？各寫一項。</summary>

AI：自動規劃清潔路線，避開障礙物，並逐漸學習最有效的清潔方法。IoT：用戶以智能電話遙距開關機械人，並收到清潔進度和電量通知。
</details>

<details><summary>12. 寫出使用生成式 AI 可能帶來的一個社會問題。</summary>

可以製造深度偽造的圖像和影片，散播假新聞，誤導公眾；或生成的內容可能侵犯他人的版權。
</details>
